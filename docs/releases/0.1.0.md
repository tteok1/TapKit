# TapKit 0.1.0 Windows 开发测试版

主线 CI #139 用源码提交 `85a81d8` 构建了 Windows x64 开发安装包。安装器内置 Electron、Node、Python、MinGit、LibreOffice 和离线检索模型。采用当前用户安装，升级会检查并备份数据库，卸载界面可选择保留或清除本机资料。

Windows Server 2025 标准用户的安装生命周期、Electron、原生 Office 和 P11 联合负载均在主线 CI 通过。CI 同批的 0.1.1 包用来验证升级和失败恢复。

该版本为未签名开发候选。干净 Windows 11 客户端验收、正式签名与下载地址待配置。正式发布前以与签名后文件一致的版本清单和校验值为准。

P11-03 本地重建了带补充许可材料的 0.1.0。该候选与 CI 基线各有独立的文件哈希。见 [本地候选验证](../evidence/P11-03/verification.json)。
