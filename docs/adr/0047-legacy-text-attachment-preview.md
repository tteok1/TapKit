# ADR0047：旧文本附件的固定版本只读预览

- 日期：2026-10-11
- 状态：accepted；验证结果以 P02-02 进度和修复证据为准。
- 任务：P02-02 预览兼容修复；基线为最新 main 的 9a9e4ee。

P03 预览器要求结构 blob，但 P02 长粘贴、无路径文本附件及生成笔记使用 parserVersion=null 的已知文本兼容路径。原件和固定版本已经保存，点击新预览器却在结构读取时返回 NOT_FOUND；旧 Electron 测试仍查找材料预览弹窗，未覆盖右侧面板。

将 ADR0036 已允许的严格 UTF-8 文本读取收敛到 FileRepository.legacyText，供聊天材料和 ArtifactRepository 共用。只有 ready、parserVersion=null、既有文本扩展白名单的固定版本可读取；原件最大 400000 字节、正文最大 100000 UTF-16 字符，拒绝非法 UTF-8 和 NUL。读取前后验证 profile、owner、删除状态、固定版本及解析状态；解析状态或 parserVersion 变化拒绝陈旧结果。

预览构造仅内存存在的单块 text 视图，保留原文及字符位置，不规范化换行、不执行 HTML/Markdown、不持久化伪解析结果、不改文件状态或创建解析租约。既有已解析文件仍必须读取其结构；结构丢失不能回退到原件。PDF、Office、图片、ZIP不属于旧文本兼容范围，原生隔离要求保持。

预览选区由 Core 从同一固定版本原文计算 hash，聊天材料再次验证。旧附件在重启后仍可使用；新增附件沿用 inputs.attach，不新增 IPC 字段、依赖、迁移或模型调用。Electron 回归改为检查新面板的完整正文与重启恢复，并将 P02-02 纳入现有 CI E2E 选择。真实模型联调按用户要求保留待验，禁止以合成回归提升 live 状态。
