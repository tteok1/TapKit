# ADR 0082 本地正文画布与固定选区审阅

日期 2026-11-12，P10-01。

- 使用已锁定的 Tiptap 3.31.3。编辑源为允许有限节点和属性的文档 JSON。文字块使用 UUIDv7。图片引用固定版本的资料库 PNG，链接限 HTTP/HTTPS，正文导入按纯文本和受支持的结构处理。
- 追加 `0024_canvas.sql`。画布头按 profile 隔离，版本包含正文、批注、模板和父版本。保存用版本 ID 与 revision 做 CAS，过期保存把提交内容和基础版本批注写为独立副本。回复、文件或画布的导入来源固定。Markdown、Word 和 PDF 文件版本与画布版本在同一事务登记。
- 每窗口 500 ms 防抖，待写草稿保存在该窗口的 Renderer 本地存储，失败可重试。使用草稿请求 ID 重放收据。批注保存原选区和固定引用，能通过不变前后缀映射的更改自动移动，无法定位时显示失效。
- AI 使用现有模型目录、预算和用量账本。每条用户操作最多一次模型尝试，仅发送选区或明确选择的整文文字及显式参考。正文和参考作为数据，模型无工具。Core 对提案持有窗口、基础版本和选区哈希，应用时再次校验。整文重排仅接受已知块 ID 的完整排列。
- Markdown 保留文字结构。Word 与 PDF 使用 P07 模板和授权静态图。PDF 转换使用既有 Windows AppContainer 和 P07 文本、图片及版面检查。文件导出通过 Host 保存框的独占写入。
- 正文画布使用本地单人批注。导入为独立正文副本。原 Office 高级排版仍在延期范围。
