# ADR 0072：审批恢复时区分模型与执行额度

2026-10-30，P07真实验收发现：模型已用最后一次允许调用生成完整工具参数，具体审批通过后，恢复路径把“模型调用额度已用完”作为工具派发的拒绝条件，导致工具尚有额度也budget_stopped。

分别计算executionExhausted（活跃时间、token、工具尝试次数）及新模型调用exhausted（再加模型次数）。恢复已审批工具不发新模型请求，只按执行额度决定派发；任何实际工具仍通过Gateway派发前额度、grant、内容/版本、租约和来源复验。新模型请求仍按完整额度门禁，不能多调用一次。

任务失败/额度终止时取消proposed/approved且side_effect=none的未派发动作，保留审批/账本历史。启动恢复同样清理旧终结任务的这类遗留项；dispatched/pending/unknown及未知副作用不自动取消或重放。终结任务本身仍不可恢复派发，真实补验使用新任务，不修改旧终态或伪造旧回执。

没有新增任务状态、SQL迁移或放宽单根预算。P07-03.approval-budget与P06审批回归覆盖最后一次模型调用成功完成审批工具、工具尝试已耗尽拒绝且保留原件、旧终态未派发清理和unknown保持。实际结果见progress及证据，不以文档存在代替通过。
