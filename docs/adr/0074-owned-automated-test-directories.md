# ADR 0074：自动测试临时目录所有权与收尾

- 日期：2026-10-30
- 范围：P00-01 测试基础设施维护；不进入 P08，不改变生产数据库备份策略。

## 问题

自动测试通过原生 mkdtemp 创建独立资料目录，结束时关闭数据库或 Electron，但通常不删除目录。每个新数据库又按既有策略逐版迁移并备份，叠加浏览器缓存，导致本机测试残留持续增长。.test-data 同时保存开发资料和真实验收账户，不能整体删除，也不能仅凭目录名称自动收养已有目录。

## 决策

自动 unit/integration/perf/E2E 的目录分配统一经过 scripts/test-temp.mjs，保留现有路径前缀以兼容原生隔离用例。工厂仅登记本进程新建目录及文件系统身份，拒绝 .test-data 之外的路径和带链接的父目录；清理时再次核对边界、目录类型和身份，防止误删替换后的目录。

Vitest setup 在收集时清除继承的 TAPKIT_DATA_DIR，实际执行文件的 beforeAll 才创建新的目录，并在文件 afterAll 清理，避免整文件跳过时留下默认空目录；Playwright 使用统一 worker fixture，在测试自身关闭 Electron 等资源后清理。默认清理成功和失败测试的数据，报告、截图及历史验收证据沿用既有位置。TAPKIT_KEEP_TEST_DATA=1 是显式调试保留选项。清理失败会使收尾失败，不隐藏残留。

pnpm check 加入原生临时目录导入与 Playwright fixture 检查，避免新增测试重新绕过公共收尾。真实 live 入口、开发启动器、既有账户目录和生产迁移/每日备份策略保持独立，不加入自动删除。

### 2026-10-31 跨阶段交接补充

CI72发现P03原生预览集成把临时profile路径写给后续Electron用例，afterAll清理后消费者ENOENT。跨阶段数据改为test-results下固定单份handoff.json，数据库关闭后只保存合成SQLite与内容寻址Blob，排除迁移备份、临时缓存和密钥目录；使用文件数/体积上限及整体/逐文件SHA-256验证。源资料和桌面新副本仍照常清理，不延长整个临时目录生命周期。下一次生产覆盖同一交接文件，失败生产先使旧产物失效，发布使用原子替换；消费者不读取仓库历史manifest中的临时路径。

只有本进程已登记的新建父目录可参与打包或还原，已有目录、链接和越界/损坏条目拒绝处理；这不是收养已有用户profile或放宽自动删除范围。协议仅用于合成测试资料，不修改生产备份或应用数据格式。

## 本轮本机清理与验证

旧残留按用户具体批准的清单单次处理，保留含凭据/真实验收目录、近24小时修改及未识别目录。清理前后核对292个重要资料目录内9289个文件，原字节全部一致；私有逐文件清单留在 Git 忽略的本地维护目录，仓库只记录汇总。

普通退出的收尾不等于强制终止进程时也能完成清理；强制终止或显式调试保留的目录仍需单独核对，不能将旧目录自动视为本进程所有。具体命令、失败历史和最终结果见 docs/evidence/P00-01/test-data-cleanup-2026-10-30/summary.json。
