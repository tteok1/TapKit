# ADR0044：项目范围、独立索引版本与原子资料切换

日期：2026-10-10。任务：P03-03。状态：实施，验证以progress为准。

沿用projects、sessions、files/file_versions、parsed_documents、resource_links，不引入第二套资料身份或执行状态。schema11追加项目显示/默认模型/回答偏好/有限只读工具和三个默认关闭的外部背景开关；记忆表在本任务定义scope契约，自动提取/管理仍属于P04。现有0004为费用迁移，项目迁移使用0011并同步Core握手，历史迁移不改写。

resource_links追加active_index_version、pending_version_id和项目关联自身的分类/有效期。fileVersion决定不可变原件，indexVersion决定已完成结构与搜索投影。初次关联未就绪资料保持preparing；替换进入pending，新结构与搜索文本准备成功才在completeParse同一SQLite事务切换source指针与active索引。失败/OCR/取消保留完整旧版。异步读取前后核对资源关联、索引版本与profile；读取跨切换返回CONFLICT，由调用方重新读取完整快照，不合并两个版本。

本次资料范围保存于sessions.settings_json的projectScope。发送展开当前项目的显式引用为固定文件refs，并保存查询版本集合；selectedVersionIds=[]明确没有资料，null表示发送时全部当前项目资料。仅依据项目资料禁用个人指令/项目外记忆及历史工具；开关只开放对应背景类型，其他项目不会因开关而获得许可。Core工具网关再次验证资源关联，模型输出不能修改授权。项目规则优先于个人风格，但工具能力仍是固定只读集合和项目默认工具的交集。

项目删除需CAS及无活动run/标题请求；默认detach会话和解除资料关联，可选择会话回收及独占资料回收；共享文件不删除。复制克隆会话可见分支与关联，使用共享不可变文件版本，分类目录独立复制。导出通过Host私有保存框向Core发ZIP目标授权，Renderer不能给任意路径；独占创建，前后校验资料及项目revision，窗口关闭/退出取消；限制200MiB，超限可逐项下载，已有输出不覆盖。

URL入口保存公开链接及用户提供的本地正文快照，不读取网络，也不标记空正文ready。手动文本使用应用已知原文生成结构，无上传文件宿主解析回退。已连接应用、网页抓取、混合检索/冲突答案质量、自动记忆和工作执行仍按后续任务边界处理；本任务返回原文定位/缺失或过期资料诊断，并为模型明确证据不足和冲突说明规则。
