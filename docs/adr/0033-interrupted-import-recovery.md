# ADR 0033：中断导入的持久检查点

日期：2026-10-06。状态：accepted（实现中）。

复用request_receipts，不增加迁移或同义任务表。在源读取前先提交files.import.start检查点，ID由批次requestId确定，payload沿用规范化参数及selectionWindowId，保存有界token/名称/尺寸和初始状态，不保存原件路径或句柄。逐项导入、版本、引用及解析job仍在原有同步事务与files.import.item收据内提交；不持事务跨I/O。

新FileService从开始检查点、完整批次和逐项收据恢复视图。没有完整批次时显示interrupted；已提交项保留真实结果，缺收据项标为导入未完成/PERMISSION_DENIED，要求重新选择原件。重放完全相同旧请求仅提交恢复结果，不读取源、不创建版本；改参数/窗口继续由收据hash拒绝。重新选择未完成原件使用新token和新请求；不自动沿用过期授权，也不盲目补做未知副作用。

files.importHistory最多查看最近100个开始检查点，只展示非活动的中断批次。files.dismissImport验证同profile记录且拒绝运行中批次，以稳定收据保存隐藏标记；隐藏提示不删除原件或幂等收据，重启后仍隐藏，明确按ID查询历史结果仍可返回。Renderer在库页列出逐项结果与重新选择提示，区分导入状态和解析状态。

真实合成进程验收：编译当前FileService/FileSelections/Store，第一项事务提交后暂停第二项读取，由父测试终止这个确切进程；重新打开SQLite验证第一项/版本/job保留，第二项缺授权，旧请求重放不重复，重选第二项才新增文件。真实Electron打开同一合成数据库显示恢复提示，并验隐藏后重启仍生效。此测试不启动parser或native helper，不冒充真实AppContainer验收。

旧版本没有开始检查点的历史半批次无法完整重建；新检查点适用于本次源码之后创建的批次。后续ADR0034实现带租约标记的解析暂存后台清理；任务使用记录及R15后的原生诊断仍待本任务收口。
