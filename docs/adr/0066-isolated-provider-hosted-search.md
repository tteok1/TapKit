# ADR0066：隔离的模型通道托管搜索

- 状态：accepted，2026-10-27 用户要求先设计再实施。
- 替代：ADR0064 的 Tavily 选择、凭据和 live 资源；保留安全读取、快照与引用。

用户不接受额外搜索依赖，要求参考 AelionBot/Codex。由当前模型通道执行隔离托管搜索，TapKit 保留 Agent 循环、权限、预算、来源读取和核验。独立搜索只携带本轮问题与筛选配置，绑定同一账号/run 单次结算。具体接口与验收见 [P05 设计](../plan/17-hosted-web-search.md)。

不换成 Codex app-server，不实现 MCP 或网页搜索爬虫。兼容协议不等于服务可用；不静默换账号、重试或回退 Tavily。额外搜索费用未知，真实账号验收独立于 fixture，未过范围保留 implemented_not_live_verified。

真实端点的 model_not_found 暴露锁定目录过期，按官方 gpt-6.1-sol 元数据增加单模型适配与真实 low 思考声明，不替换默认模型/依赖。无额外网络目录拉取；模型列表仍可离线显示。用户追加授权最多两次同范围公开搜索；前两次失败记录保留。
