# ADR 0084 本机数据包、清理与恢复

日期 2026-11-13，P10-03。

- 可移植 ZIP v1 由 `manifest.json`、`data.json` 和 `objects/<sha256>` 组成。Core 使用白名单投影导出会话分支及正文、项目元数据、原文件版本和记忆。校验格式、成员数量和总解压大小、正文与对象哈希后才导入。会话、项目、文件、版本和关联换成本机 ID。历史消息以记录形式导入，导入记忆可查看，模型上下文只读取已验证的有效记忆。
- 分类清理使用对象 ID、revision、关联计数和备份范围计算影响摘要。SQLite 事务撤访问、擦除派生内容并登记现有持久队列。在事务提交前同步写独立删除日志。Core 重启或恢复旧快照时重放日志。文件字节在无活动引用及保留快照引用时回收。默认清理包含目标资料的本机恢复快照。
- 本机备份通过 SQLite Backup API 创建快照，清空 native 状态，最后发布校验清单。按本地日期保留最近 7 份自动快照。恢复选择后先验证候选和安全快照，Core 停止后通过同盘替换切换数据库，并隔离原件。读写启动失败时，专用子进程在临时数据库应用删除日志，再从已验证的快照导出可移植资料。
- 数据目录由 Host 单实例锁保护。系统对话框确定目标，暂停 Core 后逐文件复制和校验，新目录完整后才原子更新启动指针。原位置留作回退。仍有活跃 Git 工作树时，先处理工作树的绝对路径关系。
- 隐私页的聊天保存开关使用现有本机偏好 CAS。关闭后首页走临时会话，既有聊天可读。产品反馈诊断选项默认关闭，由用户确认反馈后使用。账户管理继续由现有连接页负责。
