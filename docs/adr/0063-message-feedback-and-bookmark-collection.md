# ADR 0063：本地反馈入口、可取消评分与收藏列表

- 日期：2026-10-26
- 状态：accepted
- 任务：P02-03；对应 FR-07-018、FR-07-020，人工清单 T14。

用户在人工测试中发现点踩没有反馈入口、无法集中查看收藏，并要求再次点击同一评分可以取消。

点赞/点踩沿用 `messages.mark`：再次点击当前评分传 `rating:null`，切换评分仍互斥；不改收藏、反馈说明或举报标记。首次点踩写入成功并刷新后打开本地反馈框；取消反馈框只关闭编辑，保留已经保存的评分。更多菜单可重新打开并加载已保存的说明和举报标记，保存失败保留输入并在框内提示。使用原生 dialog 支持键盘、Escape 和焦点恢复，说明反馈仅存本机、不发送给模型服务商。

按2026-10-26用户后续截图要求，“收藏”入口位于“聊天”页顶部“归档”和“回收站”之间，打开既有 `/bookmarks` 列表；侧栏不单列收藏，收藏页的“聊天”入口保持高亮，原四个常用导航继续排序。沿用现有主题和列表样式，显示会话名、最多500字符的消息摘要、归档标记，支持查看原消息和取消收藏。打开时读取当前会话 revision，必要时通过原 CAS 分支切换定位收藏的原消息；运行中无法切分支时显示错误，不重新执行模型或工具。

新增只读 `messages.bookmarks`：输入仅 `{cursor?,limit?}`，默认50/最大100；输出 `{bookmarks:[{messageId,sessionId,branchId,sessionTitle,snippet,createdAt,archived}],nextCursor}`。按消息创建时间和ID降序，使用经严格校验的键集游标；列表中的用户/助手消息均来自现有 `message_marks`，不新建收藏实体或修改数据库。查询同时限定当前profile、message/session/branch归属，过滤回收站、消息删除、系统说明节点及session/message墓碑，允许归档和非当前分支的收藏；临时库拒绝查询且临时收藏不进入持久库。取消收藏与评分/反馈独立。

本轮不增加云反馈、外部举报、模型请求、迁移或新的收藏笔记副本；人工验收与自动化证据分开记录，原live/gate不提前提升。
