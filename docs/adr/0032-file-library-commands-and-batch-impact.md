# ADR 0032：文件库界面与批量影响预览

日期：2026-10-06。状态：accepted（实现中）。

文件路由使用既有Host/Core文件桥接。Renderer不接收路径或原件字节；多选和目录来自Host选择token，拖入使用真实DOM File交给preload。导入前读取files.importInfo的锁定limits和statfs可用空间；关闭未导入选择调用files.releaseSelection，只释放本窗口token。

files.list增加updatedAfter/updatedBefore毫秒边界，验证起止顺序，与名称/当前版本内容、格式、来源、owner、folder、收藏、回收站和排序共同绑定分页游标。界面每页50项、跨页最多选择100项；刷新及详情使用序号拒绝过时回复，异步操作结束刷新当前筛选。库/项目folder层级复用既有文件夹，不另建目录状态。

files.versions与files.usage显式trash标记允许查看本profile回收站元数据；原件下载仍拒绝删除状态。新增files.impact接受FileBatchSchema，逐项验证profile/owner并返回完整FileView数组，任何项无权限或缺失时整次预览失败。删除确认展示每项名称和实际关联范围，永久删除/移除引用分别调用已有命令；确认执行时Core重新验证，预览不充当权限授权。

移动与下载按项执行并展示完成/失败/取消结果。保存框取消后停止后续保存框，保留所有未完成项选中。恢复和清理缓存保持已有原子批次语义；不把部分结果呈现为整批成功。版本恢复新增版本，另存副本和原件下载均可选择固定旧版；读取失败保留原件入口。

文件库提供列表/网格、筛选、目录创建、元数据及版本详情、引用目标、回收站和去重存储占用。明暗主题、中文长名和应用设置200%缩放用真实Electron验收；对话框仅在测试中返回合成路径，Host/preload/Core/SQLite仍使用实际链路，不宣称交互式系统选择框已人工验收。本机解析能力失败关闭，未执行被阻止的helper；真实原生验收仍受R15阻塞。任务使用记录、崩溃恢复及图像原件体验尚待本任务收口。
