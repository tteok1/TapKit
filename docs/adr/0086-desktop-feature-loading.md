# ADR 0086 桌面功能按需加载

日期 2026-11-16，P11-01。

首页加载共享界面和聊天输入。画布、资料预览、终端和富文本渲染在各自的使用入口加载，由 Vite 输出到独立资源。私有包 `@tapkit/ui` 为画布编辑器、终端和 Markdown 渲染提供独立子路径，避免共享入口执行这些模块的初始化和样式导入。

聊天首次加载 Markdown 渲染器期间直接显示转义后的正文，组件加载完成后按现有 Markdown、公式和引用逻辑呈现。画布、预览与终端在加载时显示各自的状态。生产构建压缩渲染脚本，开发服务沿用现有配置。

首次加载 Markdown 期间的正文使用已有流式正文样式，正式 Markdown 渲染标识由加载后的组件提供。依赖格式化结果的复制、选区与公式流程据此等待完成。

Host 启动时仍应用 Chromium 网络隔离设置。网页读取和浏览器运行时在首次请求时加载，加载完成后确认请求仍来自当前 Core。网页读取和取消共用初始化，保持首次加载期间的取消顺序。

验证同时覆盖静置首页、首次打开按需功能，以及聊天流式、引用和 Office 的联合负载。性能仍按应用实际进程的工作集、启动和流式展示门槛验收。
