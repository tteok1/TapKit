# ADR0058：圆角外壳、历史管理入口与会话排列偏好

- 日期：2026-10-22
- 状态：采纳，用户确认排序规则
- 范围：P02-01 首页/外壳，关联 P02-03 既有会话组织能力

## 交互决定

首页标语更新为“你的想法，从这里开始”。内容向输入框靠近，推荐问题采用胶囊轮廓，与输入框左边缘对齐，隐藏/展示按钮与右边缘对齐；三模式共享草稿及待添加附件保持 ADR0057。短窗口/大缩放下推荐区独立滚动，输入框仍停靠底部。

侧栏品牌右侧固定通知、搜索两个图标（从左到右），原入口与独立首页链接移除。主区域左上用圆角分栏图标切换整个侧栏，移除前进/后退按钮；收起后不保留图标栏或空白占位。正常启动/重启默认首页，显式 openEntity 新窗口仍打开目标实体。侧栏宽度、展开状态、滚动与每页位置仍独立保存在窗口布局中。

侧栏只显示活跃会话，移除状态筛选条；归档与回收站迁入设置分类，独立页面复用现有恢复、归档、删除影响预览及永久删除确认，不改变生命周期、记忆清理或权限。支持按标题、聊天/工作、项目过滤。会话快捷操作在 hover、键盘聚焦或菜单打开时展示；触摸设备始终可达。新建分组及排列选项放入“最近”标题右侧更多菜单。可见图标、提示与控件使用圆角及圆头线条。

## 排序契约与兼容

用户明确确认：默认“最近更新”，置顶优先；“手动排序”允许拖拽，每个分组独立保存。DesktopSettings 增加 historySort（updated/manual，旧数据默认 updated），通过既有 settings.set/CAS 保存并同步其他窗口。旧 sort_key 和组归属保持；切换模式不清空手动顺序。Renderer 拖放或 Alt+上下箭头仅重排同组、同置顶状态条目，跨组移动仍走既有移动命令。

sessions.list 增加 sort（默认 updated）与 query（裁剪后最多 240 字符，默认空）。updated 按 last_activity_at 降序，避免仅查看会话使列表跳动；manual 先按既有组内 sort_key，再按活动时间/id 稳定排序，两种都置顶优先。分页签名包含排序与查询，禁止复用其他筛选的游标；标题匹配按字面子串参数化查询，不将 `%`、`_` 或 SQL 片段解释为模式。SessionRecord 增加 sectionId（旧响应默认 null），列表利用原 join 取值，详情仍按 profile 核对组织关系。分页拖拽将可见子集替换进完整组序列的原有位置，避免未加载会话因旧默认键跳到前面。无需数据库迁移，业务 protocolVersion 保持 1。
