# ADR 0065：接收者预览、本地不可变导出与聊天开发目录

- 日期：2026-10-27
- 状态：accepted
- 任务：P05-02 / P05-03

## 决定

Core根据当前profile、会话分支及文件owner授权创建已脱敏的接收者视图。预览绑定windowId、源revision指纹、选项、内容hash与30分钟有效期；任何来源/选项变化要求重新预览。Renderer只能提供previewId/hash，保存路径由可信Host的原生保存框产生，私有命令交回Core，模型与公开IPC均不能选择本机路径。

schema16增加snapshot.export作业类型，事务重建jobs并保留旧队列及memory_candidates外键。exports只持久化选项/hash/状态/安全名称，已审正文和保存路径在窗口绑定内存中。重启将未完成导出标为中断，需重新预览，不自动重放写盘。关闭窗口/取消/租约失效阻止迟到结果；使用wx写入且不覆盖已有文件，异常只删除本次持有的文件inode，未知副作用先检查目标。

联动补充：progress85为进入写盘的持久边界；重启遇到未完成/取消且仍处于该阶段的记录，恢复SIDE_EFFECT_UNKNOWN，先检查原位置。已确认未产生或已清理本次文件的失败归零；清理失败/文件已写而状态落盘失败必须保留不确定码，取消不能覆盖它。导出记录使用实际选择的安全basename，过程摘要只输出固定中文工具名/状态。包内probe成功后清理其新建测试profile，再生成目录清单。

MD/TXT/HTML/PDF输出公开正文，ZIP显式包含固定版本的原始附件，保留安全相对目录。默认排除附件、原始日志、native状态、记忆详情、内部路径与已知凭据格式。原始附件字节不能静默脱敏，预览列出选入文件并明确要求发送前核对。仅保留实际读取来源的公开URL、已验证引用锚点和包内相对链接；HTML无脚本/远程追踪或资源。项目只导出简介及所选资料，不隐含导出项目指令或记忆。

PDF经Host私有通道进入独立非持久化、sandbox/contextIsolation、无Node/无preload/禁页面脚本的专用renderer。网络仅允许本次内存HTML和内嵌字体；CDP固定DOM/CSS命令等待字体就绪，不执行页面脚本。删除PDF主动外链，拒绝权限/下载/弹窗，超时和取消销毁窗口。Noto Sans CJK SC 2.004锁定官方commit/hash/OFL，bootstrap获取、构建再次校验和打包。PDF视觉中文正确，个别Han复制为兼容字符，精确文本使用TXT/MD，测试按NFKC另验正文而不声称原始Unicode逐码一致。

网页快照应在会话软删除时保留、恢复后可访问，只在永久清理时删除；0016修正早期0015的软删除清理触发器。回收站期间及其他会话仍不可访问。永久删除导出记录不影响用户已保存的外部副本。

pack:dir为P05聊天开发快照，保留现有appRoot相对布局，物化锁定依赖和当前Electron/Node/Python/LibreOffice/Git/helper/模型/字体资源，不包含原profile或凭据。新目录重跑原生隔离验收，失败保持fail-closed，报告不跨目录/身份转植；它不是P11安装包。

## 验证

P05-02的unit/integration、桌面五格式保存、真实沙箱PDF及无TapKit独立Edge；P05-03全链路/故障回归、目录资源清单、包内隔离重验与独立profile启动。真实模型R01—R05及搜索R06按资源状态单列。
