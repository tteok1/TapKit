# ADR 0069：P07 文档结构与受控生成边界

2026-10-28；关联 P07-01；实施中，不代表 P07-01 已验收。

## 决定

`DocumentSpec` 放在共享 contracts，schemaVersion 1。sections 的 blockId 唯一，文档总量有界；style 包含 report/proposal/minutes、name/date/brand 明确封面字段以及目录/页码选项。缺省为 report、空字段、无目录/页码，以兼容内部结构化草稿；来源包含 label 和共享 ResourceRef，引用是定位信息，不是权限。只修改指定封面字段，正文不做不加区分的全局替换；局部修改必须以 baseVersion 在持久化事务中比较，当前纯函数只生成候选，不能代替事务 CAS。

固定代码通过 docx 生成可编辑文件；Markdown 和 DOCX 从同一结构生成。三种内置大纲只创建空章节，不能被当作已完成的成果。默认 A4、20mm、Noto Sans CJK SC，正文 11pt、标题 22/16/13pt；表头重复。目录是由章节标题组成的静态清单，不宣称页面索引；页码可选。不得生成不受控 OOXML 或执行模型代码。输出需要非空内容。引用必须由调用方重新验证当次任务的已选资源及可访问版本；无授权回调或拒绝则失败。图片尚无授权字节解析器，当前拒绝，禁止根据模型提供的路径或 URL 回退读取。

## 安全与交接

当前只实现内部结构、候选修改和受控序列化，未开放模型工具，未建立持久化 CAS 和引用授权网关，未执行真正 Office 渲染。后续接入必须保留 P06 既有工具账本、租约、断点恢复和来源/项目权限，验收器不得仅凭 ZIP 签名将文档标完成。DOCX/PDF 转换必须使用既有 AppContainer 及隔离门禁；素材缺失、转换失败和版本冲突均明确失败并保留原版。此 ADR 不授权额外网络请求或本机文件路径。

2026-10-28 P07-01 补充：追加 schema18 的 document_specs，按 fileVersion 保存受限 DocumentSpec，原文件版本与元数据在同一 SQLite 事务登记；局部修改先在事务内核对 baseVersion 和文件 revision。文件永久删除及删除日志重放清除对应结构正文。此存储接口仅为基础，尚未接入生成工具，不表示已完成端到端验收。

## 2026-10-28 产品接入补充

P07 新工具目录保留 P06 旧目录的重试语义。document.create 将文件、结构和工具收据原子登记；document.revise 与 document.fields 在审阅前后绑定文件、版本、revision、参数及授权，审批通过后创建新版本，字段替换只作用于显式字段。用户的受众、语言、模板、主题、封面和目录/页码设置在创建时由 Core 约束，篇幅作为模型指引；后续修订保留已存设置。Markdown 与 DOCX 由相同结构生成，PDF 通过既有 AppContainer 转换及解析核验。来源在序列化前后及事务提交前复核；没有授权的图片仍拒绝。实现与验收进度以 P07-01 记录为准。

模型工具描述采用 API 参数校验器支持的受限 JSON Schema 子集，而非直接发送带 `$schema`、`format` 或正则的 Zod 导出。此子集用于模型参数边界的基本形状和数量检查；共享 DocumentSpec/WorkToolArgs Zod 校验、资源授权和事务检查仍是权威边界。字段更新的非空约束由共享契约执行。

PDF 结构验收另检查 A4 页尺寸与解析文字边界；解析框触及页面边缘或缺少定位则拒绝。该检查不是完整视觉布局验证，不能检测所有文字重叠；排版自动修复和授权静态图片仍未实现。图片请求在 Core 显式返回 FORMAT_UNSUPPORTED，不得降级读取路径或假报成功。

## 图片验收基础（尚未开放）

PNG 的固定版本仅可通过任务明确选择的文件引用解析；读取前后检查会话/项目访问，限制 128 KiB、像素尺寸、PNG chunk 与 CRC，固定生成器最多 8 张且总量 512 KiB，不由模型提供路径或 URL。文件解析 worker 的可选 inspectDocumentImages 输入使受控 DOCX 返回实际嵌入 PNG 的 SHA-256，PDF 返回绘制图片操作数；字段对旧 ParsedDocument 可选，不改变用户图片原件只存储的解析规则。验证仍须比较授权源字节、检查隔离转换结果及失败/恢复路径，Markdown 图片预览仍受既有安全策略限制；在这些完成前 Core 继续拒绝产品图片请求，不标已实现。

## PNG 产品接入（后续决定，替代上文“尚未开放”）

DOCX/PDF 工作允许用户明确选择静态 PNG（单张 ≤128 KiB、最多 8 张/合计 ≤512 KiB、像素受限，拒绝动画及错误 CRC），模型只见名称和固定版本引用，不读取图片。来源在渲染前后、事务提交及交付核验时重新授权；隔离解析 worker 对 DOCX 嵌入图像逐项做哈希比较，对 PDF 检查图片绘制，二者与正文、页面边界检查共同构成交付门槛。PNG → DOCX → PDF 桌面合成样例通过；Markdown 图片、JPEG 和自动排版修复不在此结果内，详见进度。

## 排版修复（后续决定，替代上文修复尚未实现）

对有授权 DocumentSpec 的 DOCX 转 PDF，原始版在隔离进程转换后，通过另一个隔离进程绑定输入哈希检查内容、图片绘制和页面边界。只有内容完整但页尺寸或边界异常时，才按固定紧凑模板重排，最多修复两次；文字、数字、来源和原 DOCX 版本保持不变。每次重排重新授权来源和图片，不运行模型生成的样式。候选只在临时目录生成，验证通过才提交成果；内容缺失、三次排版仍失败或权限失效时不提交。进程状态未知时保留临时目录供恢复，不盲目重试；只有验证后的 finished 身份允许恢复成果。边界检查无法识别全部视觉重叠。
