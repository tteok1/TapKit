# ADR 0088 · IPC 审计使用有序异步文件操作

日期：2026-11-24，P11-01。

联合负载的测试进程采样发现 Host 同步审计写入阻塞事件循环。改为单队列异步目录、轮转、清理和追加，保留原来每份 1 MiB 轮转与 14 天保留规则。每条记录只保存 requestId、command、ok 和错误 code，不保留请求、回复正文或凭据。

调用方仍等待记录写入成功后才返回 IPC 回复，写入失败继续传给调用方；一次失败不会阻断之后的记录。退出前排空已完成请求排队的审计写入。此调整不改变 IPC 协议、授权、业务事务或日志内容，也不把未落盘操作宣称为成功。

聊天取消的收尾查询同时绑定 session_id 与 run_id，利用既有会话索引，避免在 100,000 条全局历史中扫描。保留原事务和消息状态更新。验证覆盖队列顺序、轮转与保留、正文不入日志、失败恢复，以及聊天取消与联合负载。
