# ADR0059：分组实际展开与统一悬停提示

- 日期：2026-10-22
- 状态：采纳，按用户最新截图修正
- 范围：P02-01 外壳，关联 P02-03 会话分组与 Markdown 控件

## 分组与列表契约

侧栏分组箭头与名称均展开/收起该分组内的会话、项目；不再把名称点击解释为筛选下面的统一列表。已分组会话只在所属分组内出现，“最近”呈现未分组活跃会话，所有活跃会话可通过展开各组访问；聊天/工作主列表仍支持完整历史筛选。原分组 collapsed 和组内手动排序仍持久化，置顶优先，拖拽与 Alt+上下保持同组限制。

sessions.list 的 sectionId 从可选 ID 扩展为可选 ID/null：省略表示全部，ID 表示对应组，null 表示未分组。三种范围使用独立分页签名；后台参数化查询并保留 profile 限制。组展开按现有 limit=50 读取，组内独立“加载更多”，有界保留最多 100 条；收起不查询会话，移除组仍按原逻辑保留会话。无需数据库迁移或新服务，protocolVersion 保持 1。

## 提示与排版

所有应用自己编写的原生 title 悬停提示迁为 data-tooltip，由 packages/ui 单一委托层显示同一圆角、主题色提示框。保留 iframe title 的可访问文档命名。支持 hover、键盘聚焦、禁用控件、动态 Markdown；不为每个控件安装全局监听。提示位于浏览器顶层，按视口/缩放约束，点击/Escape/滚动时关闭并恢复原 aria-describedby。三模式说明首选在下方，其余默认上方并在屏幕边缘调整。

分组标题、菜单项目与子菜单返回标题都保持图标/文字同一行；排序勾选置于右侧。标语和模式条间距略增，推荐问题移除尾部箭头。沿用原圆角外观、草稿、模型和翻译逻辑。

## 验证

证据写入 docs/evidence/P02-03/group-tooltips-2026-10-22，包含真实分组展开/收起/分页/重启、菜单几何与截图、禁用发送提示、模式说明下方位置、复制/选区回归、服务与静态检查。工程结果以最终回执为准，不提升真人或阶段 gate 状态。
