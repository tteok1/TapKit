# ADR 0083 桌面偏好、快速输入与帮助

日期 2026-11-12，P10-02。

- 在 DesktopSettings v1 上追加带默认值的字段。既有配置和数据库迁移版本保持可读，设置写入复用 profile revision CAS。全部恢复在同一 SQLite 事务核对桌面与模型偏好 revision，再恢复两套 profile 默认值。默认首页、窗口与模型继续使用各自已有入口。日期地区、格式和时区作用于会话与文件日期。文件库的本周筛选按所选时区和周起始日计算。
- 规划页面仅使用本地路由。Availability 区分 available、placeholder 和 hidden。未来能力由设置列出，规划页仅提供聊天与项目导航。
- Host 在成功读取或保存设置后注册快捷键，检查窗口内重复和系统占用。快速输入使用受同一 Host 约束的独立窗口，草稿随当前窗口转入统一开始页，发送须另行确认。登录启动只在 Windows 安装构建应用，Host 报告实际注册状态。
- 保存对话和原件仍须经过原有 Host 选择框。配置的下载目录仅作为有效初始位置，外部打开沿用原件权限验证。
- 帮助使用当前构建的版本与本地连接摘要。诊断、用户贴入片段和所选静态截图均为显式选项，本地预览后可保存附件。版本、服务状态和 GitHub Issues 由用户主动在浏览器查看。
