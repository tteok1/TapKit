# ADR 0081 版本化的本地网站预览

- 状态：已采纳
- 日期：2026-11-12
- 任务：P09-04

网站以纯 HTML 或锁定 React/Vite 模板进入当前任务的私有代码工作区。Core 将网站 brief、版本索引和区域来源记录保存在既有项目及 worktree 状态中，继续使用 code diff、逐文件版本校验、工作修订和 P09-02 Node 沙箱。React 依赖由用户显式授权通过既有 broker 准备。broker 校验锁内全部条目，仅下载与当前平台和架构兼容的可选包；网站的 npm 安装禁用依赖脚本。

本机实测 Vite 在 Windows AppContainer 的构建转换阶段超时。React 模板的默认 `npm run build` 在沙箱内读取锁定的 React 生产模块，写出自包含的静态资源。导出保留同一套应用源码、Vite 及其 Rollup WASM 锁，独立开发环境可用 `npm run build:vite` 打包。此处没有放宽进程、文件或联网约束。

构建写入当前工作区的私有临时输出目录。Core 核对真实进程退出状态和源码哈希，再保存固定源码及有限静态文件的快照。构建失败保留上一次成功版本。恢复校验当前源码哈希，写入失败时按前像逆序恢复并核对结果。工作区存在未构建修改时，可将历史版本复制到同一会话的新工作。页面选择以固定版本 ID、源码哈希和 DOM 摘要绑定。页面摘要进入不可信代码上下文。

Host 的私有通道接收已经核对的产物字节。只读 HTTP 服务在随机回环端口提供确切的白名单路径和随机租约。独立沙箱 WebContentsView 无 preload，按会话阻断其他地址、导航、下载、文件选择和权限请求。窗口关闭、租约失效和工作状态变化结束服务。源码 ZIP 由 Core 从固定版本的受控源码生成，Host 通过系统保存框交付。

React 模板以查询参数切换页面。静态服务仅将租约根路径映射到已知的 `index.html`。源码恢复沿用既有文件变更日志，导出提供依赖锁和构建命令。参考图理解和公网发布延期。
