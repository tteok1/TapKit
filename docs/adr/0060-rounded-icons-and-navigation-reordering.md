# ADR0060：圆滑图标与长按导航排序

- 日期：2026-10-23
- 状态：采纳，按用户最新三项要求
- 范围：P02-01 桌面外壳；前端改动，无 Core/IPC/数据库变更

新建任务、聊天、工作、项目、文件、置顶、设置采用现有依赖 Lucide 中带弧线过渡的图形（SquarePen、MessageCircle、BriefcaseBusiness、Folder、FileText、Pin、Settings），保留共享18px/1.65描边与圆头圆角、主题色。替换原本轮廓尖锐的自绘路径，不仅修改 strokeLinejoin。设置分类中归档、回收站只保留文字及原路由。

删除“调整导航入口”及隐藏选项、上移按钮。四个主导航始终显示，通知仍在品牌右侧。主导航按住450ms进入拖动预览；8px以上的提前移动取消准备，松手提交到既有窗口布局 localStorage。预览通过CSS order移动，避免重排DOM丢失指针捕获；提交后DOM与视觉顺序一致。拖动不触发页面跳转，普通点击保持链接行为；Escape、指针取消、失去捕获、窗口失焦/尺寸改变可撤销预览。Alt+上下方向键提供键盘排序，焦点和简短读屏公告保留。

旧 layout.navigation 缺失的主导航按默认顺序补齐，保留已存在条目的相对顺序及其他窗口布局值。每次读取/保存都规范化为四项主导航加既有通知键；兼容原契约，不迁移数据库、不新增后台接口，不支持隐藏某项。排序沿用当前窗口槽位的持久化范围。

验证以 docs/evidence/P02-03/navigation-icons-2026-10-23 为准：普通点击、真实长按/拖动、快速移动取消/Escape、键盘排序、旧隐藏项恢复及重启；正常浅色与窄窗200%深色、图标实际截图，设置分类仍能跳转。只使用隔离profile，保留原窗口/profile及既有UI与翻译改动，不发真实模型请求、不提交推送或提升gate。
