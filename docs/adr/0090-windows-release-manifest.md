# ADR 0090 Windows 发布清单

状态为接受，2026-11-25。

P11-03 在 P11-02 的手动下载入口上共用一份版本清单。清单固定版本、Windows 平台、x64 架构、资产名、字节数、HTTPS 地址、SHA-256、签名状态、最低系统与版本说明地址。

开发候选保持未签名，清单的资产与版本说明地址为空。下载页从清单生成。正式下载要求配置品牌图片、站点地址、签名验收结论及指向指定仓库版本标签的准确资产地址。仓库、品牌和站点地址集中于 distribution.config.json。

桌面更新从用户本来就可主动查询的 GitHub Release 中选取较新稳定版本。它先核对清单资产自身的大小和 SHA-256，再将清单和 GitHub 安装器资产的版本、地址、大小、SHA-256 对照。下载仍由用户确认，保存前再次流式校验成品。没有合规清单时，更新入口保持可用并等待符合条件的发布。

发布准备工作流仅为人工选择的主线标签构建开发候选及验收证据。R09 实机、R10 Logo、R11 正式签名和 R12 下载地址按独立资源记录。
