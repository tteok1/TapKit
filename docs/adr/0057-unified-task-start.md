# ADR0057：统一新建任务页与共享草稿

- 日期：2026-10-22
- 状态：采纳，按用户明确确认的交互实施
- 范围：P02-01 首页；复用 P02-02 草稿/附件及 P02-03 临时聊天

## 背景与决定

用户要求首页、新建聊天、临时聊天及工作共用设计页，并明确选择三个模式共用文字和附件草稿。侧栏只保留“新建任务”，Ctrl+N 同样进入首页；项目创建放在项目页。首页保留“从这里开始”，提供聊天/临时聊天/工作横向单选条与 hover 说明。各模式推荐问题只填入草稿，隐藏后仍有展示入口，沿用既有 showSuggestions 偏好。输入框停靠内容区底部，上方内容独立滚动。

切换模式不重挂载 ChatSurface，不创建会话，不清空文字、引用和待添加 File。首次提交按所选模式创建普通聊天、临时聊天或工作草稿，然后复用既有导入、草稿和发送命令。工作只保存草稿，不开放 P05/P06 执行。尚未配置模型时，输入框显示“请先配置模型再使用...”，右下提供“设置模型”到模型连接页；已有账户暂不可用不等同未配置。

## 引用查询与授权

inputs.references 的 sessionId 改为可选。无 sessionId 仅查询当前 profile 的文件和可明确引用的历史消息，不创建占位会话，也不持久化新建页草稿。有 sessionId 时保留原项目范围、固定版本、删除状态及权限核验。无会话查询不授予项目整体引用权限；过期消息版本仍拒绝。发送时以最终目标会话重新核验引用。

物理附件仍只走 preload 分类、Host 单次选择令牌与 Core 文件导入；只有原有无路径 File 走字节兼容通道。首页只延迟导入，不读取物理 File 字节，不扩大临时聊天或项目文件权限。部分导入成功项从待添加列表移除，失败项保留；页面切换仍取消未开始导入，已提交结果只归原会话。临时聊天仍使用原内存服务及退出清理。

## 验证与限制

测试覆盖无账户、推荐隐藏/恢复、键盘模式切换、共享文字/附件、工作草稿、普通发送、临时清理、引用权限、物理导入及导航取消。实际命令、结果、失败和截图见 docs/evidence/P02-03/unified-start-2026-10-22；当前进展见 P02-01 交接。本次不改变工作执行、真实模型验收或阶段门禁状态。
