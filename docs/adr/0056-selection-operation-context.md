# ADR0056：选区操作使用本轮动作与核验原文的独立上下文

- 日期：2026-10-19
- 状态：accepted
- 任务：P02-03 / FR-07-017，批测T13缺陷修复

用户在“操作”验收会话选中英文并点击翻译，模型返回上一轮要求的固定回复。只读核对确认选区messageId/version/UTF-16范围及英文均正确，新用户消息确为翻译请求，供应商产生一次新attempt并完成；回复与上一轮相同。该轮无checkpoint，仍带完整会话历史及5条自动背景引用。既有ADR0054已隔离背景的system角色，但普通聊天全历史并不适合作为独立选区动作的输入；不能由这些元数据断言供应商内部如何作出回答。

`messages.transform`仍创建普通用户轮并附原引用，原会话、消息、分支与旧失败回复保留。HistoryService经原schema、权限、版本和范围校验后，通过Core内部参数写入固定动作枚举`selectionOperation`；Renderer不能在`messages.send`里指定该字段，不新增IPC或数据库迁移。该标识与引用随队列和消息持久化；普通后续轮没有标识，仍按原历史规则装配。

选区轮只装配该轮目标和Core再次核验的选区原文，原文使用JSON数据包装，不把用户选中文字拼入system。固定`message.selection`产品模块只描述动作/边界，翻译遵循明确回答语言偏好；auto时中文译英文，其他原文译简体中文。保留既有个人回答偏好、项目与产品规则，不提供工具，不载入其他聊天/记忆背景或历史checkpoint。供应商意外返回工具调用时，在工具登记和执行前拒绝，沿用原partial/错误回执语义，不伪称工具执行。

选区与目标计入原模型窗口、根预算和用量账本；超出限制直接停止，不用全会话压缩补入旧目标。快照版本追加`selection-v1`，来源只记录本轮消息与实际选区引用。所有原生状态、账号、渠道、隔离及普通聊天装配保持原约定。

2026-10-20补充：真人翻译已产生正确译文，但模型把输入中的messageId作为`evidence`标记输出，随后被知识引用账本拒绝，run为partial/VALIDATION_ERROR；界面又将通用校验错误误报为文件选择错误。选区来源仍作为原消息的版本/范围引用持久化并可预览，但供应商仅接收JSON原文，不接收来源ID；固定选区规则明确不要求知识证据标记，快照改为`selection-v2`。这类无检索/无工具的文字变换不调用知识证据校验或写citations表；普通聊天的真实知识引用继续严格校验，不把消息ID注册成文件证据。

选区响应在流式保存前投影：移除模型额外添加的内部`evidence`标记，并暂存跨片段的不完整标记；选中原文本来包含的协议/代码示例按字面保留。只处理新的选区轮，不改写已有失败回复，且不新增模型重试。界面将消息范围来源标为“所选原文”，点击仍通过正式引用命令校验并预览原句；混合来源称“引用来源”。通用VALIDATION_ERROR使用操作校验提示，不再一律声称选择了文件。

同一动作重放采用原`messages.transform`规范化请求作为收据指纹，客户端消息hash同时绑定动作；修复此前委托`messages.send`收据与外层transform不一致造成的CONFLICT，不重复产生消息/轮次或供应商请求。引用过期、无效范围和Renderer伪造字段继续拒绝。

工程验证覆盖五种动作的实际canonical输入、选区边界、原历史保持、重放、普通后续历史恢复、预算不足及意外工具。固定传输只核对装配/生命周期，不能证明真实模型已正确翻译。用户需要在修复构建中重新选中原英文、执行一次翻译；保留旧失败，不自动重发。其他已过内容不重复，非管理员及其他渠道继续按用户要求暂缓。证据见docs/evidence/P02-03/selection-operation-2026-10-19/。

2026-10-21补充selection-v3：用户23:21翻译同一英文，原始53字符范围、translate动作及selection-v2快照均正确，真实响应却与原文SHA完全相同；昨日成功中文也使用v2和相同上下文统计，近期UI修复没有改变Core翻译实现。因此不归咎于选区/网络，也不从元数据推断供应商内部原因。当前auto只作为一段条件提示，存在模型自行理解方向及原样回显被当成completed的缺口。

Core在本轮开始时把翻译目标解析为明确zh-CN或en：显式回答语言优先，auto沿用原约定（含汉字原文译英文，其他原文译简体中文）。本轮canonical用户指令、message.selection模块及answer-preferences使用同一个目标；不持久修改个人/会话语言偏好，不把来源数据变成system指令。其他四种选区动作与普通聊天装配保持，快照升级selection-v3。

新增错误码TRANSLATION_UNCHANGED：对明显中英文自然句子跨语言翻译却原样回显的情况，在消息final/completed前拦截，保留原始返回/来源并记interrupted/partial，中文提示可手动重试或换模型；不自动新增请求或费用，不改旧失败。检查是保守回显检测，不是通用译文质量或语言判定：标识符、数字、URL、含代码符号内容、产品名列表及源/目标同语言不据此拒绝。明确英文句以至少四个英文词、句末标点且含普通小写词识别；中文自然句以至少八个汉字并含句末标点识别。隔离传输验证输入与错误生命周期；真实模型质量仍需新构建下单次复验，不据此提升真人/gate状态。
