## 实现与边界

- GitHub 工作区界面覆盖 PAT 连接、按权限克隆和刷新基准、编辑生成的提交说明、提交与推送审阅、创建 Draft PR，以及查看检查和审查反馈。复用现有代码审阅和终端。
- PAT 按资料配置和工作 ID 加密存入 Host Vault。Git 和 REST 分别使用固定的 GitHub.com 地址。应用核对仓库 ID、用户选择的权限、会话联网限制和当前任务版本。
- 提交只包含已接受且具备当前测试回执的文件。推送核对基准和远端分支 SHA。Draft PR 核对仓库、分支、提交和工作标记。远端结果未知时，用户可以重启后继续查询持久回执。
- 实现决定见 [ADR 0080](../adr/0080-reviewed-github-publication.md)，同步了 IPC 和工具隔离规格。工作区发布记录沿用 schema 23 的状态文档。
