# 总开发顺序与阶段入口

本文件只梳理依赖和任务摘要，不安排日历日期或工期。详细实现位于每个任务独立Markdown，共享契约是统一约束。默认按本表顺序执行；同阶段依赖满足后可调整独立任务顺序，但不要求多Agent并行开发。

具体交付深度和阶段收口见[15阶段标准](15-stage-deliverables.md)。实际进度由项目docs/progress记录，不写进本静态时间线；初始化和换会话提示见[14使用说明](14-codex-workflow.md)。

## 里程碑

- M0：P00完成，工程/存储/通信/Windows运行隔离可验证。
- M1：P05完成，可从源码运行完整聊天体验。
- M2：P11-01完成，纳入范围的完整开发版本及系统验收报告。
- M3：P11-02完成，可在干净Windows安装运行。
- M4：P11-03完成，开源和官网分发资料就绪；实际公开发布依赖指定仓库、签名和地址。

真实账号未提供只阻塞对应live验收；未通过OS隔离不能验收依赖它的任意代码执行。所有版本都将“已实施”“已真实验收”“占位”“延期”分开标记。
