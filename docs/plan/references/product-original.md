# 通用型 Agent 产品需求清单

> 版本：V1\.0｜日期：2026\-09\-14｜视角：用户可见、可操作的功能。
本文为完整产品功能池，不限定首发范围；仅列功能与交互，不涉及技术实现。桌面端、移动端、团队版及创作者功能按章节标明适用范围。
借鉴 ChatGPT、Codex 等产品的交互组织，以下条目是本产品拟开发需求，不代表任一参考产品已具备全部功能。

## 01\. 产品结构与主要入口

|界面区域|主要内容|
|---|---|
|左侧导航|新建、搜索、聊天、工作、项目、文件库、智能体、插件市场、定时任务、通知|
|顶部栏|当前空间、项目、会话标题、模式、模型、分享、更多操作|
|中央主区域|首页、聊天记录、工作过程、列表与详情页面|
|底部输入区|文本、附件、语音、工具、上下文引用、发送与停止|
|右侧工作面板|文件预览、编辑画布、网页、来源、任务详情|
|左下角账户区|个人资料、设置、用量、订阅、空间切换、退出|

**名词约定**：会话承载交流；任务承载一次工作；项目归集相关会话与资料；空间区分个人或团队资源；成果指生成的文件、页面或其他可交付内容。

## 02\. 注册、登录与首次使用

### 2\.1 账户访问

* [ ] 不需要注册登录，用户安装下载到本地，打开就能用。

* [ ] 支持修改个人信息（头像、昵称）

* [ ] 个人信息页可以查看用户协议与隐私政策。

### 2\.2 新用户引导

* [ ] 绑定 API Keys / OAuth 登录其他 agent 的订阅服务（先支持 Codex 的）

## 03\. 首页与新建入口

* [ ] 一键新建聊天、工作任务、项目。

* [ ] 首页直接输入问题、拖入文件、粘贴图片。

* [ ] 可选聊天/工作模式（默认打开聊天）。

* [ ] 展示常用智能体、工具、模板和最近使用入口。

* [ ] 展示最近会话、置顶会话、项目、文件。展示会话有正在处理的任务或者有未读的消息。

* [ ] 展示运行中任务、待确认事项。

* [ ] 点击示例提示词，填入输入框或进入对应模板。

* [ ] 隐藏不需要的推荐内容。

* [ ] 无历史记录时展示简洁的使用引导。

## 04\. 侧边栏与全局导航

### 4\.1 布局与导航

* [ ] 展开、收起侧边栏，拖动调整宽度。

* [ ] 高亮当前页面，记住展开状态与滚动位置。

* [ ] 按时间顺序展示会话。

* [ ] 会话条目显示标题、更新时间、运行状态与未读标记。

* [ ] 悬停显示完整标题与快捷操作。

* [ ] 列表分页或连续加载，支持展开更多。

* [ ] 前进、后退，返回之前查看的位置。

* [ ] 在新标签页或独立窗口打开会话、项目。

### 4\.2 自定义组织

* [ ] 置顶、取消置顶会话与项目。

* [ ] 创建、重命名、删除自定义分组。

* [ ] 拖动调整分组、项目和会话顺序。

* [ ] 将会话移入、移出项目或自定义分组。

* [ ] 折叠分组，显示组内未读与运行任务数量。

* [ ] 删除分组时保留组内会话，并说明去向。

* [ ] 显示、隐藏或调整常用导航入口。

* [ ] 通过右键菜单执行重命名、归档、分享等操作。

## 05\. 全局搜索与快速操作

* [ ] 搜索会话标题、项目、文件和任务。

* [ ] 按相关性或更新时间排序。

* [ ] 展示命中片段，突出关键词。

* [ ] 点击结果定位到具体消息、文件或任务。

* [ ] 在当前会话、项目、文件内单独搜索。

* [ ] 查看、删除搜索历史会话。

* [ ] 搜索仅展示当前用户有权访问的内容。

## 06\. 聊天输入区

### 6\.1 文本输入

* [ ] 多行输入、自动增高、展开大输入框。

* [ ] 设置回车发送或回车换行。

* [ ] 粘贴富文本、表格、代码与链接。

* [ ] 超长粘贴内容可转为文本附件。

* [ ] 保存各会话草稿，切换页面后恢复。

* [ ] 显示输入长度限制，超限时保留草稿并提示。

* [ ] 支持输入撤销、重做与清空。

* [ ] 支持快捷指令和个人常用提示词。

### 6\.2 附件与上下文

* [ ] 通过按钮、拖拽、粘贴添加一个或多个附件。

* [ ] 从文件库、项目资料、已连接应用选择材料。

* [ ] 拍照、截图后添加到输入区。

* [ ] 通过 @ 引用文件、项目、智能体、插件和已有会话。

* [ ] 引用消息片段、文件选区、网页内容继续提问。

* [ ] 显示已选材料的名称、来源、处理状态。

* [ ] 发送前预览、替换、移除附件与引用。

* [ ] 材料未就绪时提示等待、重试或移除。

* [ ] 明确显示本轮启用的模式、模型和工具。

### 6\.3 发送与补充

* [ ] 发送消息后显示发送中、已发送、失败状态。

* [ ] 失败消息可编辑、重发，避免重复提交。

* [ ] 回复期间继续输入，选择立即补充或排队发送。

* [ ] 查看、编辑、取消尚未执行的排队消息。

* [ ] 停止当前回复，保留已生成内容。

## 07\. 消息展示与操作

### 7\.1 内容展示

* [ ] 逐步显示回复，标识正在回答或正在执行。

* [ ] 展示标题、列表、表格、引用、链接与分隔线。

* [ ] 展示代码高亮、数学公式和图表。

* [ ] 展示图片、音频、视频、文件与交互内容卡片。

* [ ] 展示网页来源、文件引用与可点击定位。

* [ ] 长内容、工具过程和来源列表可折叠。

* [ ] 展示任务进展摘要、关键步骤与耗时。

* [ ] 显示回复使用的模型及必要的时间信息。

* [ ] 新消息自动跟随；阅读历史时不强制滚动。

* [ ] 一键回到最新消息，标记未读回复。

### 7\.2 消息操作

* [ ] 复制整条回复、选中文本、代码块和表格。

* [ ] 编辑已发送的问题，重新生成后续回复。

* [ ] 重新生成回答，切换并查看不同回答版本。

* [ ] 指定其他模型重新回答。

* [ ] 从任意消息创建分支会话，保留原会话。

* [ ] 引用回复继续追问，或选择快捷后续问题。

* [ ] 对选中内容执行翻译、解释、扩写、缩写、改写。

* [ ] 收藏消息，保存为笔记或项目资料。

* [ ] 朗读回复，控制播放、暂停与速度。

* [ ] 点赞、点踩、反馈问题、举报内容。

* [ ] 删除消息时说明后续内容如何处理。

* [ ] 将回答转为文档、任务或可复用模板。

## 08\. 会话管理

* [ ] 自动生成标题，支持手动或让 AI 重命名。

* [ ] 查看、继续历史会话。

* [ ] 复制会话，选择是否携带附件。

* [ ] 为会话添加标签、备注。

* [ ] 归档、取消归档，搜索已归档会话。

* [ ] 删除会话，批量归档、移动或删除。

* [ ] 从回收站恢复，或永久删除会话。

* [ ] 分享会话，导出为 Markdown、PDF 或纯文本。

* [ ] 将会话移入项目，显示将采用的项目资料与规则。

* [ ] 查看当前会话使用的文件、工具和个性化设置。

* [ ] 长会话生成上下文摘要，支持查看和纠正。

* [ ] 新会话接续已有会话摘要，选择保留哪些背景。

* [ ] 临时聊天：明确历史保存、记忆使用与清理规则。

* [ ] 刷新或重新进入后恢复消息、草稿和任务状态。

## 09\. 模型、模式与回答偏好

* [ ] 查看可用模型、能力简介、适用场景与用量限制。

* [ ] 自动选择模型，或手动指定模型。

* [ ] 搜索、收藏模型，设置默认模型。

* [ ] 切换快速回答、深入思考及可用的思考强度。

* [ ] 切换聊天、工作、研究和创作模式。

* [ ] 切换前说明附件、工具和会话上下文的兼容情况。

* [ ] 设置回答语言、长度、语气和输出格式。

* [ ] 显示当前设置的生效范围：本次、会话或默认。

* [ ] 模型不可用或额度不足时选择其他可用模型。

* [ ] 自动更换模型时显示实际使用的模型。

* [ ] 查看当前模型不支持的能力，并获得可用替代入口。

## 10\. 工作模式与任务创建

### 10\.1 任务定义

* [ ] 用自然语言描述目标，上传参考资料。

* [ ] 指定成果类型、数量、语言、受众与格式。

* [ ] 指定截止时间、工作范围和完成标准。

* [ ] 选择所属项目、使用材料、智能体与工具。

* [ ] 通过简短问题补全需求，支持选项与自由回答。

* [ ] 选择直接执行或先查看计划。

* [ ] 查看、修改、删除、重排计划步骤。

* [ ] 选择执行全部计划或指定步骤。

* [ ] 设置时间或用量上限，达到上限后通知用户。

* [ ] 保存任务配置，复用为模板。

### 10\.2 执行过程

* [ ] 查看待开始、排队、运行、等待输入、暂停、完成、失败、取消状态。

* [ ] 查看当前步骤、已完成步骤、待办事项与阶段成果。

* [ ] 查看正在使用的工具、资料来源和操作结果摘要。

* [ ] 运行中补充材料、修改要求，看到调整后的计划。

* [ ] 暂停、继续、取消任务。

* [ ] 切换会话后任务继续运行，后台任务可随时找回。

* [ ] 明确提示关闭页面后是否继续、是否需要设备保持在线。

* [ ] 在需要判断时回答问题、批准操作或拒绝操作。

* [ ] 从失败步骤重试，或跳过非必要步骤继续。

* [ ] 中断恢复后显示接续位置与未完成事项。

### 10\.3 任务交付

* [ ] 集中展示结果摘要、成果文件与关键来源。

* [ ] 区分已完成、部分完成、失败与仍待用户处理的内容。

* [ ] 对成果提出修改，继续当前任务。

* [ ] 接受成果、退回修改，标记任务完成。

* [ ] 一键预览、下载、分享或保存成果到项目。

* [ ] 查看完成时间、实际耗时与用量。

* [ ] 将当前任务转为重复执行的定时任务。

## 11\. 任务中心与多任务协作

* [ ] 集中查看全部工作任务，支持列表与看板。

* [ ] 按项目、智能体、状态、时间筛选任务。

* [ ] 搜索、排序、置顶、归档任务。

* [ ] 新建、复制任务，调整排队优先级。

* [ ] 同时跟踪多个任务，显示运行数量与容量限制。

* [ ] 将复杂任务拆为子任务，查看负责人、依赖与结果。

* [ ] 将子任务交给不同智能体，并统一汇总成果。

* [ ] 向指定子任务补充要求，单独暂停或重试。

* [ ] 查看主任务与子任务之间的跳转关系。

* [ ] 批量暂停、取消或归档选中的任务。

* [ ] 查看任务活动记录和历史成果。

## 12\. 项目与知识资料

### 12\.1 项目管理

* [ ] 创建项目，设置名称、图标、颜色和简介。

* [ ] 查看项目内的会话、任务、文件、来源和成果。

* [ ] 在项目中发起聊天或工作，复用项目背景。

* [ ] 设置项目专属说明、回答偏好和默认工具。

* [ ] 查看、修改项目指令，显示与个人偏好的关系。

* [ ] 收藏、搜索、排序、复制和归档项目。

* [ ] 删除项目时说明会话、资料和成果的处理方式。

* [ ] 导出项目资料及成果。

### 12\.2 知识资料

* [ ] 上传文件、添加网页链接、手动录入笔记。

* [ ] 从已连接应用导入指定资料。

* [ ] 资料按文件夹、标签分类。

* [ ] 查看材料准备中、可使用、失败、已过期状态。

* [ ] 查看资料来源、更新时间和适用范围。

* [ ] 更新、替换资料，查看历史版本。

* [ ] 选择本次仅使用哪些资料，或仅依据项目资料回答。

* [ ] 回答引用可定位到原文、页码或表格位置。

* [ ] 显示资料缺失、相互冲突或无法支持结论的情况。

* [ ] 移除资料后提示对相关任务的影响。

* [ ] 设置项目独立记忆，控制是否使用项目外背景。

## 13\. 文件上传与导入

* [ ] 上传文档、表格、演示文稿、PDF、文本和代码文件。

* [ ] 上传图片、音频、视频和压缩包。

* [ ] 批量上传，导入文件夹并保留目录关系。

* [ ] 从云盘、应用、分享链接导入文件。

* [ ] 上传前显示支持格式、大小、数量与剩余空间。

* [ ] 每个文件显示进度、取消、重试与失败原因。

* [ ] 上传后区分上传成功与内容读取完成。

* [ ] 重复或同名文件可选择保留、替换或另存。

* [ ] 对加密、损坏、空文件和不支持格式给出处理入口。

* [ ] 对图片扫描文档提供文字识别结果与失败提示。

* [ ] 选择将文件用于当前会话、保存到项目或文件库。

* [ ] 文件读取失败时仍可下载原文件。

## 14\. 文件库与下载

### 14\.1 文件管理

* [ ] 汇总上传文件与生成成果，支持列表、网格视图。

* [ ] 按类型、来源、所属项目、时间筛选。

* [ ] 搜索文件名及可检索的文件内容。

* [ ] 查看文件名、格式、大小、所有者和更新时间。

* [ ] 新建文件夹，重命名、移动、复制、收藏文件。

* [ ] 批量选择、移动、下载、删除文件。

* [ ] 查看文件关联的会话、任务与使用记录。

* [ ] 将已有文件引用到新会话或其他项目。

* [ ] 查看文件版本，恢复或另存指定版本。

* [ ] 删除文件前区分移除引用与删除原文件。

* [ ] 回收站恢复、永久删除，显示保留期限。

* [ ] 查看存储占用，按大小清理文件。

### 14\.2 下载与导出

* [ ] 下载原文件、生成文件或指定历史版本。

* [ ] 选择导出格式，并说明格式转换的限制。

* [ ] 多个文件打包下载，保留目录结构。

* [ ] 查看下载或导出进度，失败后重试。

* [ ] 文件失效时显示原因，并提供重新生成入口。

* [ ] 桌面端选择保存位置，下载后打开文件或所在目录。

* [ ] 导出任务全部成果，附带清晰的文件名称。

## 15\. 文件预览与右侧工作面板

### 15\.1 通用预览

* [ ] 在消息卡片中预览，在右侧面板展开。

* [ ] 拖动调整面板宽度，展开全屏、关闭或切换标签。

* [ ] 多文件同时打开，聊天与预览并排查看。

* [ ] 显示文件名、类型、版本、页数与大小。

* [ ] 搜索内容、复制选区、下载、分享、外部打开。

* [ ] 从引用直接定位到具体段落、页码、单元格或时间点。

* [ ] 选中文字、框选区域或添加批注后向 AI 提问。

* [ ] 切换文件后记住阅读位置。

* [ ] 文件更新后刷新预览，提示当前版本变化。

* [ ] 预览失败时提供重试、下载和外部打开。

### 15\.2 各类文件预览

|文件类型|用户可用功能|
|---|---|
|PDF|翻页、缩略图、目录、缩放、搜索、选区与批注|
|Word / 文本文档|阅读、目录、搜索、复制、段落定位|

|图片|放大、缩小、旋转、适应窗口、原图查看|
|音频|播放、暂停、进度、倍速、转写文本定位|
|视频|播放、全屏、字幕、进度、关键片段定位|
|网页 / HTML|页面交互、刷新、预览与源码切换|
|压缩包|查看目录、查看文件信息、提取选中文件|

## 16\. 文档画布与内容编辑

* [ ] 将回复或文件打开到独立编辑画布。

* [ ] 手动编辑标题、正文、列表、表格、链接和图片。

* [ ] 选中内容要求 AI 改写、翻译、扩写、精简或校对。

* [ ] 针对局部提出修改，保留其他内容。

* [ ] 对整份内容调整语气、结构、篇幅和语言。

* [ ] 添加、回复、解决批注。

* [ ] 查看 AI 修改前后的差异，逐项接受或拒绝。

* [ ] 撤销、重做、自动保存，显示保存状态。

* [ ] 查看版本历史、恢复旧版、保存副本。

* [ ] 使用已有文档作为内容或样式参考。

* [ ] 导出 Markdown、Word、PDF 等适用格式。

* [ ] 长文支持目录跳转、字数统计和查找替换。

## 17\. 办公成果与数据分析

### 17\.1 文档与演示文稿

* [ ] 生成报告、方案、邮件、简历、会议纪要等内容。

* [ ] 根据资料生成大纲，再生成完整文档。

* [ ] 选择模板、主题、语言、篇幅和目标读者。

* [ ] 批量替换姓名、日期、品牌等指定内容。

* [ ] 生成演示文稿，设置页数、比例和视觉风格。

* [ ] 逐页预览，修改标题、文字、图片和备注。

* [ ] 增删、复制、重排幻灯片。

## 33\. 多端体验与无障碍

### 33\.1 多端使用

* [ ] 跨设备接续任务，查看另一设备生成的结果。

* [ ] 移动端拍照上传、语音输入、系统分享导入。

* [ ] 移动端接收完成通知，回答问题或批准操作。

* [ ] 桌面端通过快捷键呼出快速输入窗口。

* [ ] 桌面端截图、拖入文件、关联本地文件夹。

* [ ] 连接可信远程设备，查看状态并停止远程任务。

* [ ] 网络断开时保留草稿，恢复后继续提交或同步。

### 33\.2 易用性与无障碍

* [ ] 小屏幕下导航与预览可收起，内容不遮挡输入区。

* [ ] 主要操作支持键盘完成，焦点位置清晰。

* [ ] 按钮、输入框、图片与状态可被读屏识别。

* [ ] 支持高对比度、文字放大和减少动态效果。

* [ ] 状态同时使用文字说明，不只依赖颜色。

* [ ] 音视频提供字幕或转写入口。

## 36\. 帮助、反馈与异常体验

### 36\.1 帮助与支持

* [ ] 搜索帮助文档，查看常见问题和操作指南。

* [ ] 查看快捷键、功能介绍与示例任务。

* [ ] 查看版本号、更新记录和新功能说明。

* [ ] 提交问题或建议，可附带截图和相关会话。

* [ ] 提交前选择是否附带诊断信息与内容片段。

* [ ] 查看反馈进度，接收支持回复。

* [ ] 查看服务状态、故障公告与维护通知。

### 36\.2 通用状态与恢复

* [ ] 所有列表提供加载中、空内容、无结果和加载失败状态。

* [ ] 耗时操作显示正在做什么，并提供取消入口。

* [ ] 网络失败时保留已输入、已上传和已生成内容。

* [ ] 超时、额度不足、权限不足时提供具体恢复操作。

* [ ] 删除、覆盖、撤销分享等操作说明对象与影响。

* [ ] 可恢复操作提供撤销或回收站入口。

* [ ] 文件、模型、插件或来源失效时提供替换入口。

* [ ] 外部操作结果不明时显示待核对，避免直接重复提交。

* [ ] 同步冲突时保留副本，让用户选择需要的版本。

* [ ] 重试只作用于指定失败事项，明确可能产生的额外费用。

## 37\. 关键用户路径核对

* [ ] 新用户登录 → 新建聊天 → 收到回答 → 找回历史会话。

* [ ] 上传文件 → 确认读取完成 → 提问 → 点击引用定位原文。

* [ ] 发起工作 → 查看计划 → 补充要求 → 预览成果 → 修改 → 下载。

* [ ] 长任务后台运行 → 收到通知 → 返回任务 → 继续处理。

* [ ] 创建项目 → 添加资料与规则 → 新建多个会话 → 复用项目背景。

* [ ] 安装插件 → 连接账号 → 选择资料 → 执行操作 → 查看结果 → 撤销权限。

* [ ] 创建智能体或模板 → 试用 → 保存 → 再次调用。

* [ ] 创建定时任务 → 试运行 → 查看下一次时间 → 接收结果 → 暂停。

* [ ] 分享成果 → 接收者访问 → 评论或下载 → 所有者撤销分享。

* [ ] 任务失败或断网 → 保留已有结果 → 处理原因 → 从中断处继续。

* [ ] 达到用量限制 → 查看恢复时间或升级 → 返回原任务。

* [ ] 导出个人数据 → 清理内容或注销账号 → 查看处理结果。
