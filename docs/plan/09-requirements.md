# 原始需求逐项追踪

用户最后答复优先于原始功能池。“实现”表示纳入待开发范围，不表示当前已经完成。任务验收后coding agent应另添实施状态/测试/证据列，不能直接把本范围列改成“已完成”。

| 状态 | 含义 |
|---|---|
| 实现 | 在本轮详细方案中实现 |
| 调整实现 | 依据本地/无账号/预览优先等决定调整交互 |
| 部分实现 | 原条目含多个能力，仅明确子集纳入 |
| 占位 | 只设计状态页面，对应底层能力不实现 |
| 延期 | 不在本轮设计实现方案 |

原始checkbox 547 条，补充表格映射9条，共556条。范围统计：实现310，部分实现29，调整实现33，延期99，占位85。

表中来源按原始章节编号。原件副本：[产品需求](references/product-original.md)、[策略设计](references/strategy-original.md)。
