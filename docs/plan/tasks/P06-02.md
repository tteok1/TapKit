开放工作模式的受控写入与执行工具，审批绑定可审阅的真实动作。

前置：[P06-01 持久化工作任务、计划和执行编排](P06-01.md)、[P00-03 Windows隔离与文件运行组件验证](P00-03.md)

执行前按[阅读地图](../16-reading-map.md)定位P06-02行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P06部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

产品10.2/31.1；策略12/21/22/27。已有授权复用，不要求低风险动作反复确认。

- FR-31-001（实现）：查看 Agent 可访问的文件、应用、网页和设备。
- FR-31-002（实现）：对权限选择本次允许、会话允许、持续允许或拒绝。
- FR-31-003（部分实现）：发送、发布、删除、购买等操作前查看具体内容与对象。
- FR-31-004（实现）：可编辑待执行内容，再批准或拒绝。
- FR-31-005（实现）：查看已授予权限，缩小范围或撤销授权。
- FR-31-006（实现）：查看关键操作记录及执行结果。
- FR-31-007（部分实现）：授权变化后提示对正在运行和定时任务的影响。

## 代码位置与输入输出

主要变更：packages/tools/{registry,gateway,approval,artifact}、apps/desktop/src/renderer/features/approvals、tests/security/approvals。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 工具注册表按共享签名声明权限、副作用、重试、输出上限；只读聊天只能得到read/artifact_write子集，工作模式也不能超grant。名称schema版本按run固定。
2. 工具提出后依次校验schema、资源归属、taskVersion、预算、授权；需要批准时先准备diff/表单/仓库/正文等preview，再写approval和waiting_user。批量动作逐项计算风险，不能通过脚本逃过批准。
3. 消费批准前重算args/resource/content hash，TTL/taskVersion/撤权任一变化即失效；用户编辑待执行内容产生新preview。拒绝后给替代路径，不自动换其他工具执行同动作。
4. 调用意图先持久化再派发；result状态按success/partial/unknown等登记，只有safe错误可重试。将执行环境产生文件登记为versioned artifact，验证格式可打开/内容schema/预览后才对用户发布。
5. 暂先开放固定文件生成/Office转换/Python分析与授权workspace patch；任意exec工具仍需P09项目运行环境完善。结果过长外置受控blob，UI/模型只拿摘要引用。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
