# P11-01 系统评测、故障回归与源码开发版交付

## 任务摘要与前置条件

对全部纳入功能做跨模块验收，交付可从源码运行的完整开发版本。

前置：[P10-03 数据导出、清理、备份和恢复闭环](P10-03.md)

执行前按[阅读地图](../16-reading-map.md)定位P11-01行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P11部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

用户第25项先交付源码/开发版本；占位/延期明确不计为已实现能力。

- FR-37-002（实现）：上传文件 → 确认读取完成 → 提问 → 点击引用定位原文。
- FR-37-003（实现）：发起工作 → 查看计划 → 补充要求 → 预览成果 → 修改 → 下载。
- FR-37-004（实现）：长任务后台运行 → 收到通知 → 返回任务 → 继续处理。
- FR-37-005（实现）：创建项目 → 添加资料与规则 → 新建多个会话 → 复用项目背景。
- FR-37-010（实现）：任务失败或断网 → 保留已有结果 → 处理原因 → 从中断处继续。

## 代码位置与输入输出

主要变更：tests/{evals,security,recovery,perf,live,e2e}、docs/evidence、README.md、CONTRIBUTING.md、CHANGELOG.md。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 按共享质量文档补齐T01-T22、60例保留集、同预算子Agent消融和代表Office视觉检查；每结果记录commit/model/prompt/OS/用量来源，模型裁判需人工校准。
2. 回归跨模块链：订阅耗尽时带RAG/记忆工作切API；进程重启后审批过期；删除资料后旧checkpoint/cache访问拒绝；子任务返回旧版本；GitHub超时不重复写。
3. 在标准基准数据和硬件运行perf并定位不达项，修复主线程阻塞、DB长事务、大列表、嵌入争用；供应商延迟单列。达到安全硬门槛后才能形成交付候选。
4. CI分普通PR(check/unit/integration/build)、受控Windows安全(helper)、人工触发live(真实secrets，仅可信代码)，fork PR永不访问secret。原生runtime必要测试无可用环境不得自动跳过算成功。
5. 清点需求追踪表：每纳入项有task/test/evidence；延期/占位带理由。无凭据渠道为implemented_not_live_verified，列资源ID；真实资源到位后补测到全部通过，不能从范围删掉。
6. README给出Windows源码启动、依赖自动准备、模型连接、数据路径、支持格式、能力边界和故障恢复；交付dev目录包及checksums。所有任务进度留可接续文件，不只留聊天总结。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。

## 测试与验收

根命令check/unit/integration/e2e/security/recovery/perf/eval全部执行；live按R01-R08实测；无秘密扫描源码/日志/构建包。验收报告区分通过/失败/外部待验收和范围排除，不用一个总“100%完成”覆盖它们。

执行pnpm check、与改动相关的unit/integration，以及pnpm test:e2e -- --grep P11-01（纯基础模块可由同标签integration覆盖）；涉及真实服务再执行对应test:live。命令和结果必须来自真实运行，测试命名包含任务ID。

## 完成与交接

- 上述需求对应的界面/接口真实可用，无可点击“假成功”；迁移可重跑且历史数据保留。
- 测试和故障分支达到本任务条件；影响既有功能时补相关回归，不无故重复无关全套测试。
- 将变更、测试命令/退出码、证据路径、未完成资源项写到docs/progress/P11-01.md，更新需求追踪状态。
- 依赖契约有变化必须同步shared docs/类型/fixtures；不把技术选择留给下一任务猜测。
- 仅占位任务按“状态页可用、底层不可调用”验收，不宣称延期能力已实现。
