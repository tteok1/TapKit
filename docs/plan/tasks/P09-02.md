## 技术实现步骤

1. 根据package.json/package-lock或pyproject/requirements识别Node/Python，不执行仓库脚本发现环境；RuntimeProfile保存版本、cwd、依赖锁hash、允许命令和输出目录。其他语言可浏览修改，运行标未支持。
2. DependencyBroker按共享隔离策略准备registry缓存，然后AppContainer离线安装；下载进度/许可/失败可见，禁止继承用户.npmrc/pip配置、任意VCS源和宿主密钥。
3. exec.run只接受runtime枚举和argv数组、规范化cwd、timeout；不要拼shell字符串。明确需要PowerShell语法时用受限powershell进程和固定编码输入文件，仍在同一Job中。
4. ConPTY通过helper桥接到xterm，支持输入/resize/stop、ANSI渲染和日志回看；terminal用户输入不能绕过root目录与网络边界。默认不自动打开额外OS控制台。
5. Agent按项目测试脚本和变更范围执行测试/lint/build，保存argv/cwd/exitCode/start/end/logRef；退出码不为0不能标检查通过。失败最多2次修复迭代，预算耗尽输出真实未完成。
6. 恢复先核对当前HEAD/hash/依赖锁/进程身份，再决定重跑验证。相同PID可能复用，必须组合helperInstance+startTime/runId。
