输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 从数据契约创建profile/settings/session/message/event/outbox/job/provider/budget/file及授权基础表；其他领域迁移留到所属任务。Core唯一写DB；第一次启动创建local profile和默认设置，启动前先迁移/恢复。
2. 实现Request/Reply/EventEnvelope、版本握手、命令白名单、Zod校验、requestId去重和events.replay。Host验证sender/frame；Renderer订阅更新只拿EntityView。未来未实现命令不注册，返回FEATURE_NOT_AVAILABLE。
3. 创建Host VaultService，以safeStorage加密、按credentialId保存在DATA/secrets；IPC入站secret立即脱离业务日志。测试明文搜索DB/log/IPC录制不出现测试key；Windows加密不可用时拒绝持久保存，不降级明文。
4. jobs/outbox采用lease_epoch、5s心跳/15s租约、稳定dedupe_key；后台worker执行出库后再回写结果，无模型请求在事务内。实现可取消job和单次消费防重。
5. 实现blob落盘的staging/rename/DB登记和GC，备份接口用SQLite backup API。删除相关字段和墓碑从基础建模，后续不能以日志不可变阻止删除。
6. Host持有单实例锁；第二个进程把打开意图转给第一个。多个窗口不创建第二个Core写库。UI关闭不立即丢后台job，明确退出按安全关闭流程。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
