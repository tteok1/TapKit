# P09-04 网站生成和本地交互预览

## 任务摘要与前置条件

基于编程能力生成可下载网站源码，在应用内预览静态产物。

前置：[P09-02 终端、依赖准备与代码测试执行](P09-02.md)

执行前按[阅读地图](../16-reading-map.md)定位P09-04行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P09部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

产品22.2的生成/修改/预览/版本/源码下载；公网发布与自定义域名延期。

- FR-22-012（部分实现）：通过描述或参考图生成网站、页面和小工具。
- FR-22-013（实现）：在内置预览中操作生成的网站。
- FR-22-014（实现）：切换桌面、平板和手机预览尺寸。
- FR-22-015（实现）：指定页面区域，提出文字、样式和功能修改。
- FR-22-016（实现）：查看版本，恢复或复制已有站点。
- FR-22-020（实现）：下载网站源码及相关资源。
- FR-15-T08（实现）：网页/HTML交互、刷新、源码

## 代码位置与输入输出

主要变更：packages/workflows/coding/site、apps/desktop/src/main/preview-server、apps/desktop/src/renderer/features/site-preview。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 内置React/Vite网站模板和纯HTML模板，输入文字目标/受众/页面/样式要求，生成到任务worktree并复用代码diff/测试；参考图理解属于延期能力，此处不假装能读图。
2. 默认沙箱build生成dist，再由Host只读静态server在loopback随机端口服务；路径白名单、租约token、CSP、安全MIME、SPA fallback仅限已知index。禁止目录列表和任意文件读取。
3. 预览在独立无Node/无preload的WebContentsView，使用900/768/390像素三档视口；开发者允许的站内交互可使用本地状态，API/数据库后端不在本版动态预览承诺内。
4. 选择页面DOM区域产生selector/文本/布局摘要，用户反馈附来源版本，经Agent修改、build成功后刷新；不需屏幕控制或图像模型。版本恢复复用worktree/fileVersion语义，冲突保留副本。
5. 下载源码ZIP排除node_modules/.git/cache/secret，附README构建命令与依赖锁；“发布”仅显示明确延期说明，不产生伪URL、不触发外部部署。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
