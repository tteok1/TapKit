# P05-01 联网搜索、匿名网页读取与来源归档

## 任务摘要与前置条件

聊天中接入可追溯搜索与网页全文读取，给后续浏览器工作准备只读底座。

前置：[P04-03 自动长期记忆、历史参考与管理](P04-03.md)

执行前按[阅读地图](../16-reading-map.md)定位P05-01行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P05部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

产品18.1及21.1中的只读网页；浏览器无网站登录。搜索采用内置Tavily适配，凭据属独立可选连接。

- FR-18-001（实现）：手动开启、关闭联网搜索，或使用自动模式。
- FR-18-002（实现）：输入网址，读取网页、提取内容、总结或对比。
- FR-18-003（实现）：查看搜索状态、来源标题、摘要与访问链接。
- FR-18-004（实现）：设定时间范围、语言、地区和指定网站。
- FR-18-005（实现）：限定使用指定来源，排除不需要的网站。
- FR-18-006（实现）：回复中显示引用，点击查看对应来源内容。
- FR-18-007（实现）：无法访问来源时显示原因，可补充材料或更换来源。
- FR-18-008（实现）：保存网页摘要或搜索结果到项目。

## 代码位置与输入输出

主要变更：packages/tools/web、packages/network/browser-policy、apps/desktop/src/main/browser、tests/integration/web。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 实现Tavily POST https://api.tavily.com/search，Bearer凭据；基础模式max_results=8、include_answer=false、include_raw_content=false、include_images=false，映射时间/域名排除条件。无R06时搜索明确未配置，仍支持用户URL读取。
2. web.read先受控HTTP取HTML，用固定正文抽取器提取标题/段落/链接；动态页面交给匿名WebContentsView加载，等待DOM稳定最多15秒，不等待无穷networkidle。
3. 只读浏览器建立独立partition、拒绝持久登录和设备权限、CDP仅固定观察函数。完整NetworkPolicy和受控proxy在此实现并测试，不在P08才补SSR​​F限制。
4. 搜索结果只是候选；回答所引用网页必须成功读取正文并保存sourceId+contentHash+fetchedAt+locator。HTTP失败/验证码/需登录显示原因，不能编造内容；保存摘要到项目建立来源链接。
5. 聊天联网开关off/on/auto，auto仅在用户要求查证/时效或明确URL时启用；只依据项目资料时禁用网页并提示当前范围，不越过用户选择。
6. 搜索最多2轮、网页最多8份/轮，单页50MiB网络和20k字符模型摘要限制；长内容归档按需读取。用户取消传播到搜索/浏览器，不发送取消后的新请求。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
