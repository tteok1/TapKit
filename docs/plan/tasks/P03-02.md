# P03-02 文件预览、定位与右侧工作面板

提供并排可读预览和引用精确定位，优先完成预览而非Office编辑。

## 需求与边界

产品15及14.2；Office版式由本地转换器提供，表格可筛选排序但此时不写回源文件。

- FR-15-001（实现）：在消息卡片中预览，在右侧面板展开。
- FR-15-002（实现）：拖动调整面板宽度，展开全屏、关闭或切换标签。
- FR-15-003（实现）：多文件同时打开，聊天与预览并排查看。
- FR-15-004（实现）：显示文件名、类型、版本、页数与大小。
- FR-15-005（实现）：搜索内容、复制选区、下载、分享、外部打开。
- FR-15-006（实现）：从引用直接定位到具体段落、页码、单元格或时间点。
- FR-15-007（实现）：选中文字、框选区域或添加批注后向 AI 提问。
- FR-15-008（实现）：切换文件后记住阅读位置。
- FR-15-009（实现）：文件更新后刷新预览，提示当前版本变化。
- FR-15-010（实现）：预览失败时提供重试、下载和外部打开。
- FR-15-T01（实现）：PDF页码/目录/搜索/选区/批注
- FR-15-T02（实现）：Word/文本阅读、目录和段落定位
- FR-15-T03（实现）：Excel/CSV工作表、滚动、筛选、单元格
- FR-15-T04（实现）：PowerPoint缩略图、翻页、放映和备注
- FR-15-T05（实现）：Markdown排版/源码、代码行号/diff
- FR-15-T06（实现）：静态图片缩放/旋转，压缩包目录

## 技术实现步骤

1. 右面板支持多标签、尺寸调整/全屏/关闭、阅读位置按fileVersionId保存、版本更新提示；内部artifact scheme权限检查与当前版本校验不能省略。
2. PDF用PDF.js显示页/缩略图/目录/搜索/高亮；DOCX/PPTX经LibreOffice产生只读PDF/页面缩略图，侧边同时使用结构化文本定位段落/幻灯片/备注。Office转换坐标无法精确映射时标为段落定位，不谎称像素一致。
3. XLSX/CSV用虚拟网格分页加载100行，支持sheet切换、列类型、筛选/排序/单元格坐标、公式和缓存值展示；没有计算过的公式显示未计算，不把ExcelJS读入称为重新计算。
4. Markdown源码/预览切换，代码行号/搜索，JSON文本，图片只做静态缩放旋转，ZIP安全目录；音视频生成/理解无实现，此类附件外部打开不承诺内置播放器。
5. 选区产生ResourceRef+Locator+version+selectedTextHash给输入区；PDF页码用户从1开始，内部pageIndex从0开始。失效引用提示版本原因，不能自动跳到同名不同文件。失败可重试/下载/外部打开。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
