# P07-03 演示文稿生成与办公质量回归

## 任务摘要与前置条件

生成可编辑PPTX和PDF，支持按页自然语言修改并统一验证办公成果。

前置：[P07-02 表格分析、图表与可交互数据成果](P07-02.md)

执行前按[阅读地图](../16-reading-map.md)定位P07-03行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P07部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

产品17.1演示文稿和15预览；幻灯片拖拽式原生编辑延期，页顺序调整可通过结构化操作完成。

- FR-17-005（实现）：生成演示文稿，设置页数、比例和视觉风格。
- FR-17-006（实现）：逐页预览，修改标题、文字、图片和备注。
- FR-17-007（实现）：增删、复制、重排幻灯片。

## 代码位置与输入输出

主要变更：packages/workflows/office/slides、resources/templates/slides、tests/evals/office-suite。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. SlideDeckSpec含aspectRatio(默认16:9)、theme、slides(id,layout,title,bullets,table?,chartRef?,notes)。固定标题/正文/双栏/表格/图表5种布局，用PptxGenJS生成，不把文本绘成整页图片。
2. 内置浅色商务主题和深色演示主题；默认10页，上限50页；不做AI图像创作，需要图片可使用已存在、已授权的静态文件。
3. 逐页预览、增删复制重排、标题/正文/备注AI修改操作对SlideDeckSpec和baseVersion生效；每次生成新PPTX版本。缺失字体/素材给替代提示，不自动联网下载不可追溯图片。
4. 本地渲染PDF/缩略图，检查页数等于spec、每页标题存在、文本边界不溢出、图表值与来源对应；内容过多自动分拆或精简需保留用户关键数字。必要时降低布局密度而非裁剪文字。
5. 汇总文档/表格/PPT共用的ArtifactValidator和visual QA；模板变更跑代表集，Office特殊效果不完全兼容须列入格式限制页。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。

## 测试与验收

T07：3份10页演示，含长标题、中英混排、表格/图表/备注；PPTX打开后文本可编辑、页序正确；生成PDF与slides长度相等。至少一次局部修改确认其他页block hash不变，渲染页无明显遮挡。

执行pnpm check、与改动相关的unit/integration，以及pnpm test:e2e -- --grep P07-03（纯基础模块可由同标签integration覆盖）；涉及真实服务再执行对应test:live。命令和结果必须来自真实运行，测试命名包含任务ID。
