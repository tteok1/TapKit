自动保存有依据的长期信息，写后提示，提供搜索、纠正、删除和项目隔离。

## 技术实现步骤

1. 显式“记住/更新/忘记”走即时路径；普通任务结束生成低优先级candidate job。候选输出subject/predicate/value/scope/sourceEventIds/confidence/expiry/explicit，提取模型仅接必要用户发言和上下文来源类型。
2. 隐式保存要求至少2次独立用户事件支持同一稳定偏好、confidence≥0.85且非临时要求/敏感特征；来源不能是附件、代写对象或模型自己的摘要。未达条件skip，不创建待批准队列。
3. 写入使用scope+subject+predicate唯一active键与CAS；显式纠正优先，冲突旧值保留历史，迟到job不得覆盖新用户修改。每次写memory.changed，UI显示写后提示及“管理/撤销”，不弹确认。
4. 设置默认记忆/历史开启，项目外三个开关按决策关闭。注入最多1000 token，显式设置优先，相关性再筛；过去聊天参考必须可追溯到messageId，删除/临时/无权限记录排除。
5. 管理页支持来源、搜索、scope、编辑/删除/清空、更新时间；回答可展开“使用的记忆”。删除写墓碑，索引/cache和后台job都检查generation/deletedBefore；撤销如已有新修改则报冲突。
6. 临时模式不提取不读取不上传历史；删除会话的联动记忆规则按共享决策，删除进度可见。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
