## 技术实现步骤

1. 实现多行编辑/IME composition保护、Enter或Ctrl+Enter偏好、粘贴纯文本/表格/代码、撤销重做、每会话草稿。超长粘贴>20,000字符转文本附件候选，用户发送前可预览；最大文本100,000字符，超限保留草稿。
2. messages.send在同一事务保存用户消息、run/queued输入和event再ack。ChatRunner使用通用run状态存储，循环为装配→模型→完整工具提议→只读网关→结果→模型，受8轮/12工具上限；暂无工具时直接回答。
3. 解析Markdown、代码高亮、KaTeX和静态Mermaid，HTML禁用/消毒，禁止script和javascript:链接；流式未闭合代码块先安全文本，完成后再渲染。图表/公式渲染不得取得Node或IPC。
4. 继续输入可选立即补充或排队：补充持久化后取消本次模型请求，在安全边界按新taskVersion重组；队列允许编辑/取消，默认原run结束后依次运行。
5. 停止保留已生成正文为interrupted，不当completed。阅读历史不强行滚动，回到底部按钮恢复跟随；显示真实provider/model、用量状态、复制表格/代码和引用回复。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
