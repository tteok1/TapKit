- FR-14-015（实现）：多个文件打包下载，保留目录结构。

- FR-14-019（实现）：导出任务全部成果，附带清晰的文件名称。
- FR-28-001（调整实现）：分享会话、选中消息、文件、项目或成果。

主要变更：apps/desktop/src/renderer/features/sources、packages/workflows/export、packages/core/exports、tests/e2e/export。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 来源chip展示标题、版本/访问时间和类型，点击右面板定位；段落选区/页码/单元格与消息claim范围关联，无法验证的引用明确标记。
2. 会话/选中消息导出MD/TXT/PDF/HTML，任务文件ZIP保留安全相对目录；导出前预览接收者会看到的内容，默认不含工具原始日志、native状态、记忆详情、绝对本机路径和凭据。
3. 静态HTML只有本地CSS和内容，不含脚本/远程追踪资源；附件默认排除，用户选入才复制。所有链接重写为包内相对路径或已校验公开URL，防止内部scheme泄露。
4. PDF用专用无Node renderer生成，外链和脚本禁用，中文字体随包；大导出job显示进度、取消、重试。保存位置通过Host选择token，导出成功后可打开文件夹。
5. 分享入口名称“导出分享副本”，说明这是不可变副本、发送后不能撤销；没有团队/成员/有效期/在线下载权限的虚假控件。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
