输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 默认窗口1280×800，最小960×640；侧栏260宽(可调200-400)、正文最大800、右面板默认440(最小320)。窄窗收起右面板为抽屉，不压住输入；保存每窗口布局/滚动位置。
2. 实现首页、聊天/工作导航、项目/文件/搜索/通知入口、账户设置区；聊天默认首页，运行状态和未读与Core事件绑定。未来尚未实施的入口显示不可用说明，不造假列表。
3. 模型设置接正式OAuth/API Key流程、连接状态、兼容能力、默认模型、推理强度、后备顺序。密钥保存后仅显示尾4位；页面关闭清空输入引用，DOM中不能留完整key。
4. 设置支持主题浅/深/系统、字体/缩放、回车发送、默认目录、代理、语言占位、隐私/用量入口；所有偏好持久化，作用域层级显式显示。
5. UI token固定：正文14px、行高1.6、圆角8/12、灰阶背景+单一强调色；使用自有临时标志，不复制ChatGPT品牌资产。基础控件label、快捷键、焦点与错误状态同时设计。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
