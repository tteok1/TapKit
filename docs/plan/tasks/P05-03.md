# P05-03 聊天版本端到端验收

## 任务摘要与前置条件

形成可本地运行的聊天里程碑，修复前五阶段的联动问题。

前置：[P05-02 引用交互、会话导出和本地分享快照](P05-02.md)

执行前按[阅读地图](../16-reading-map.md)定位P05-03行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P05部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

验收范围是基础聊天、五渠道、文件/项目、检索、记忆、联网与导出；工作相关入口仍明确尚未开放。

- FR-37-001（调整实现）：新用户登录 → 新建聊天 → 收到回答 → 找回历史会话。

## 代码位置与输入输出

主要变更：tests/e2e/chat-milestone、tests/live、docs/evidence/chat-milestone.md、README.md。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 把用户路径串成测试：未配置→连接→聊天→编辑分支→导入文件→项目限定问答→连续压缩→自动记忆提示→搜索核查→导出→退出重进。
2. 故障覆盖取消/断流/Core重启/解析失败/旧版本引用/记忆删除；把发现问题修在所属模块，禁止通过关掉安全检查或隐藏错误绕过。
3. 五渠道live逐项记录R01-R05的实际model和能力；未提供账号就明确哪些待验收，交付源码可运行状态仍可用于开发测试。
4. pnpm pack:dir生成聊天开发包，包含当时所需运行时；提供Windows启动、模型设置、数据位置、支持格式和已知限制说明。该包是阶段快照，后续继续开发，不能称全部产品已完成。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。

## 测试与验收

运行check、unit、integration、T01-T12/T19/T20/T22的相关E2E和live；保留至少1个完整无剪辑路径的截图序列/日志。所有纳入聊天的需求有任务及测试映射，无“TODO实现”留在可点击路径。

执行pnpm check、与改动相关的unit/integration，以及pnpm test:e2e -- --grep P05-03（纯基础模块可由同标签integration覆盖）；涉及真实服务再执行对应test:live。命令和结果必须来自真实运行，测试命名包含任务ID。

## 完成与交接

- 上述需求对应的界面/接口真实可用，无可点击“假成功”；迁移可重跑且历史数据保留。
- 测试和故障分支达到本任务条件；影响既有功能时补相关回归，不无故重复无关全套测试。
- 将变更、测试命令/退出码、证据路径、未完成资源项写到docs/progress/P05-03.md，更新需求追踪状态。
- 依赖契约有变化必须同步shared docs/类型/fixtures；不把技术选择留给下一任务猜测。
- 仅占位任务按“状态页可用、底层不可调用”验收，不宣称延期能力已实现。
