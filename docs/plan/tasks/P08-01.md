# P08-01 匿名浏览器交互与用户接管

## 任务摘要与前置条件

在现有只读浏览器上增加受控点击、填写、标签管理及接管。

前置：[P07-03 演示文稿生成与办公质量回归](P07-03.md)、[P05-01 联网搜索、匿名网页读取与来源归档](P05-01.md)

执行前按[阅读地图](../16-reading-map.md)定位P08-01行，只读本任务需要的共享章节；阶段验收见[阶段收口](../15-stage-deliverables.md)的P08部分。新会话先核对实际docs/progress/CURRENT.md、INDEX.md与当前交接；不要重新通读整个目录。

## 需求与边界

产品21.1；不读取用户Chrome登录态，不执行其他应用/屏幕控制，不自动完成购买。

- FR-21-001（实现）：在工作面板打开网页，管理多个标签页。
- FR-21-002（实现）：前进、后退、刷新、复制地址、外部打开。
- FR-21-003（实现）：选择当前网页、标签页或选区作为任务材料。
- FR-21-004（实现）：让 Agent 搜索网页、点击页面、填写表单、整理资料。
- FR-21-005（实现）：查看当前操作页面、执行步骤和结果。
- FR-21-006（实现）：暂停操作、手动接管，再交回 Agent。
- FR-21-007（调整实现）：登录或验证码出现时交由用户处理，完成后继续。
- FR-21-008（部分实现）：提交表单、发送消息、下单前查看内容并确认。
- FR-21-009（实现）：遇到页面变化或无法继续时说明阻碍，并提供重试入口。

输入为前置任务已验证的接口、用户授权范围和fixture；输出为本任务真实运行的模块、迁移/契约变更、自动测试和验收证据。字段与状态使用共享契约，不新建同义表或第二套run状态。该任务不要求一次实现引用文档内所有后续功能。

## 技术实现步骤

1. 实现标签创建/关闭/前后/刷新/复制地址/外部打开与UI面板布局；每个根run独立匿名partition，页面重启后不承诺网站登录态持久化。
2. observe固定DOM可访问性摘要返回节点role/name/value/type、backendNodeId和snapshot版本；act只接受有限操作枚举与当前节点ID，先验证当前URL/epoch/节点属性，禁止模型传任意CDP/evaluate代码。
3. 普通导航和筛选可直接执行；form submit/发送/写入分类后产生完整预览审批。无法判定是否写入的点击先转人工接管，不静默执行。批准后目标变化立即失效。
4. 页面完成状态通过新快照/DOM已提交记录验证；超时但可能提交则unknown，提供用户核对/人工继续，不能重新点提交。
5. 用户接管后立即锁住该tab的Agent派发，用户操作完成点“交回Agent”生成新快照再继续；验证码/需网站登录时本版不代登录，说明限制并允许用户提供其他来源。设备权限保持拒绝。
6. 只在fixtures测试必要写入流程；真实网站操作仍需要用户授权的具体目标。关闭任务/撤权关闭会话并清cookie/cache/service worker，下载文件走文件导入检查。

## 异常处理与恢复

遵循共享ErrorCode、事务、幂等和生命周期规则。UI保留已输入/已生成内容，提供具体恢复动作。未知副作用不能盲目重试；安全/权限/版本校验失败不降级绕过。需要尚未配置外部资源时引用[资源ID](../11-external-todos.md)，只阻塞关联live验收。
