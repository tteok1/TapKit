# P01-03 本机预算上限补验

继续使用现有智谱普通Chat/FlashX隔离应用与test1账户。原每日Token上限已只读确认是2000000；账本基线6条、16066 Token（5条实际、1条取消估算），预留0。准备记录见[preparation.json](preparation.json)，Agent没有修改应用设置。

1. 打开“模型与用量”，生效范围选“默认”。只把“每日 Token 上限”从`2000000`改为`1`并保存；保留当前账户、快速回答、仅此模型及其余预算。
2. 返回刚才已有的会话，发送一次：`预算拦截测试：只回复OK。`
3. 预期显示达到预算上限或BUDGET_EXCEEDED，没有模型回复。回到用量账本刷新：仍应为6条、16066 Token，预留0。这里验证的是本机预算，不是供应商账户余额；预期在派发前拦截。若出现模型文字，立即停止这条回复，记录现象，不重复发送。
4. 将默认范围的“每日 Token 上限”恢复为`2000000`并保存。确认保存后显示恢复值，其他设置保持原值。无需再发送恢复测试消息；下一项聊天测试会验证正常派发。
5. 反馈拦截提示、尝试数/Token是否不变，以及上限是否恢复。若设置未保存或看到其他错误，记录该步，不通过连续重试补结果。

本轮只安排一次预期不派发的发送。不要点击连接检测、重新输入Key、调整供应商余额或故意耗尽账户。原生状态实际复用、不同供应商后备、核验价格及P02/P04测试仍分开记录，本项不证明那些分支通过。

后续Agent用[review-budget-public-state.mjs](review-budget-public-state.mjs)只读核对设置恢复、budget_stopped/error状态、provider_attempts及ledger未增加、root/daily预留0；不读取Key、消息正文或原生状态内容。
