# P02-03 固定底栏与紧凑聊天 UI

基线：`ui_fix` 从 `main/394418f19575ac6039c98e872e2312a3b62c0b7d` 创建。本轮无新分支、commit或push。

## 改动与边界

- 侧栏内容共用滚动区；固定底栏只含头像和设置，保持原路由；会话图钉有置顶/取消置顶说明。
- 消息正文下用带可访问名称/title的图标呈现常用操作，来源/记忆通过图标查看；其他操作收进“更多”。原生popover进入顶层并按缩放后的可见视口定位，内容变大/滚动/窗口调整时重定位，支持Escape、外部点击、键盘导航及保留原文选区。
- 收紧工具栏上方、消息末尾、进度与输入区的间距；滚动条移除上下箭头。输入底行整合加号菜单、信息、无框模型选择和圆形发送按钮。模型名称通过既有只读models.preview候选解析，不改变路由或发起真实模型请求。
- 合并输入框高度处理：52px起，随内容增高，上限clamp(72px, 30dvh / ui-zoom, 240px)，随后内部滚动，删除/恢复草稿时收缩。
- 回归暴露记忆表单后台刷新覆盖未保存勾选的问题；Renderer保留dirty选择、继续更新CAS revision，保存成功后同步权威值，提交期间禁用勾选。Core/Host/接口/权限不改。

## 视觉复核与交接

四份 `chat-*.png` 为最终布局截图，已成批检查。固定底栏不随内容滚动；常用图标/更多菜单、连续滚动条和输入底行符合本轮要求；长内容仍由滚动区承载。200%小窗口沿用折叠/抽屉及主区滚动规则，输入底行保持单行。桌面宽窗口在短会话时仍保留阅读区可用空间，输入区贴近窗口底部；回答末尾实际padding和进度到输入区间距已收紧。
