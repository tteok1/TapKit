# P07 办公格式边界

2026-10-30。当前提供固定模板与结构化版本修改，不是完整Office编辑器。实际验收范围见各任务verification；外部模型失败与原生导出质量分别记录。

- 文档：受管DocumentSpec生成DOCX/MD/PDF，PNG为固定静态配图；封面字段与引用必须来自授权事实。JPEG与任意远程图片未接入。
- 数据：只执行固定白名单分析，支持显式类型、Decimal、声明时区、受限公式与原生XLSX重算；不接收模型Python代码。CSV字符串做公式注入防护。交互HTML使用固定模板，原始明细是否包含由用户选择。
- 演示：标题、正文、双栏、表格、图表五布局，浅/深两主题，16:9及4:3；默认10页/最多50页。正文和表格至少18pt；长内容拆续页而非压缩小字，若仍超限则失败。输入过长的表头须精简后重试。
- 原生PPTX文字/表格/图表保持可编辑，静态PNG保持图片对象。图表仅来自已授权受管分析JSON，支持bar/line/area/pie；scatter或null值不转换。图表内部XLSX仅作有界纯值缓存，公式、宏、外链、OLE及嵌套均拒绝。
- 备注写入PPTX讲者备注并可在应用逐页查看/修改；普通页面PDF不展示讲者备注。图片修改通过附加授权PNG并反馈重生成，未实现拖拽排版。
- PDF由锁定LibreOffice在AppContainer转换并由原生Parser检查页数、标题、数字与页面矩形，再做代表集视觉QA。不是任意输入的重叠检测器，也不承诺Microsoft PowerPoint的全部特效/字体替代完全一致；未操作Microsoft PowerPoint GUI作验收。
- 未改页hash针对固定规范语义内容；增删移动可能改变自动页码，PPTX ZIP或PDF二进制hash不要求保持。旧规范、PPTX/PDF版本保留；过期基础版本拒绝，未知副作用先核对不重放。
- R13指定智谱Chat/GLM-4.7-FlashX已通过明确字段的真实数据→图表PPT、具体审批后的局部新版本与实际PDF视觉核验；范围限给定合成事实。历史断流和漏数字仍保留，不承诺任意自然语言或其他供应商的正确率。缺事实需核对，未知副作用不盲目重试。
