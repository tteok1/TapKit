# Current window icon

`tapkit-current-icon.png` is the unchanged `icon.png` from the existing Electron 44.3.0 distribution's `default_app.asar`, under Electron's MIT license. The user identified this asset in the running TapKit title bar and explicitly requested the same icon in the application sidebar. It is reused as the current application icon, not represented as a newly authored exclusive TapKit brand mark.

Origin: local pinned dependency `node_modules/electron/dist/resources/default_app.asar` → `icon.png`. No image generation, redrawing or recoloring.
